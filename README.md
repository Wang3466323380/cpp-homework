## 运行示例

以「猴子买桃」为例，在 Visual Studio 中新建一个 C++ 空项目，把 [`4-b5.cpp`](%E4%BD%9C%E4%B8%9A/4-b5%20%E7%8C%B4%E5%AD%90%E4%B9%B0%E6%A1%83/4-b5.cpp) 添加为源文件，然后按 **Ctrl + F5** 运行。

每道作业单独运行，避免把多个含有 `main` 的文件放进同一个项目。遇到引用 `bgt.h` 的作业，请把同题目录下的头文件和对应源文件一起保留。
