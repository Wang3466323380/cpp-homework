## 01｜算法、程序与三种基本结构

**课件对应：P1—9。**

### 1.1 从问题到程序

算法是解决特定问题的方法和步骤。在本课程的经典算法模型中，算法是含义明确、能够执行、能在有限步骤内完成的指令序列。一个问题可以有多种算法。

课件把算法分为数值算法和非数值算法：前者例如解方程、求函数值，后者例如事务管理、数据组织和处理。课件用“数值计算更体现运算复杂性，事务管理更体现逻辑复杂性”帮助理解；这不是严格的复杂度分类，非数值算法同样可能有大量计算。

五个基本特征：

| 特征 | 怎么理解 | 检查问题 |
|---|---|---|
| 输入 | 可以有0个或多个输入 | 是否知道算法接收什么？ |
| 输出 | 至少产生一个结果 | 是否知道最终要得到什么？ |
| 确定性 | 每一步的含义清楚 | “处理一下”“差不多”是否过于含糊？ |
| 有穷性 | 有限步骤结束，每步用时有限 | 会不会永远转下去？ |
| 有效性 | 每步都可由基本操作实现 | 是否提出了机器无法完成的操作？ |

课件在确定性中说“相同输入得到相同输出”，这里按确定性算法学习；随机算法等是后续话题，不必据此否认它们的存在。

程序由数据描述和操作描述组成。数据描述指定类型与组织形式，操作描述指定步骤。记忆式：**数据结构 + 算法 = 程序**；实际编程还涉及设计方法、语言工具和开发环境。

### 1.2 三种结构是本章的主骨架

```text
顺序：A → B → C
选择：判断条件 → 选一条路径 → 汇合
循环：判断是否继续 → 执行一轮 → 更新状态 → 再判断
```

课件强调结构清晰、单入口单出口、各部分有可能被执行、避免死循环。准确理解：三种结构本身不能自动保证程序没有死循环或不可达分支；条件与更新写错照样可能不结束。

### 1.3 五个贯穿算法表示的课件原例

| 原例 | 任务 | 结构 | 核心步骤 |
|---|---|---|---|
| 例1 | 输出一个数字的平方 | 顺序 | 读s → t=s*s → 输出t |
| 例2 | 成绩小于60时输出“不合格” | 单分支 | 读s → 判断s<60 → 真时输出 |
| 例3 | 不足60输出“不合格”，否则“合格” | 双分支 | 判断后执行两条路径之一 |
| 例4 | 输出10个输入数字的平方 | 循环 | i=0；i<10时读、算、输出、i加1 |
| 例5 | 判断100名学生是否合格 | 循环中包含选择 | 循环100次，每次读成绩并判断 |

四种表示方式：自然语言、流程图、伪代码、程序设计语言。自然语言易读但可能含糊；流程图直观，大程序容易庞杂；伪代码简洁，不必满足某一语言的全部语法；程序语言表达需要编译等过程才能运行，不是C++源码直接由CPU执行。

流程图常见约定：开始/结束用终止框，输入输出用平行四边形，处理用矩形，条件用菱形，箭头表示走向。

课件原例4、5的伪代码可统一为：

```text
BEGIN
    i = 0
    while i < 次数 {
        input s
        完成一次处理：算平方，或根据s<60输出合格情况
        i = i + 1
    }
END
```

课件还把它们改成先执行后判断的do形式。P6原思考题：如果i初值改成20，处理10个数的while版本一次都不执行；do版本仍会先执行一次。这说明两种循环不是无条件等价。

## 02｜C++语句与赋值表达式

**课件对应：P10—12。**

程序可以由多个.cpp与头文件组成；源文件中有预处理指令、全局声明和函数；函数体内有声明、执行语句等。入门先使用单源文件和main。

课件的四类语句：

| 类别 | 例子 | 作用 |
|---|---|---|
| 定义/声明语句 | `int a;` | 引入变量等名字，先声明后使用 |
| 执行语句 | `a=10;`、`max(a,b);`、`cout<<x;` | 完成运算、调用或控制流程 |
| 空语句 | `;` | 什么也不做，但在语法上是一条语句 |
| 复合语句 | `{ ... }` | 把多条语句组成一个块 |

课件列出9类控制语句：if-else、switch、break、goto、for、while、do-while、continue、return。if、while、break等是关键字，不能作为变量名。现代C++还存在其他结构，这里按课程范围学习。

**表达式和语句不同。**`a=3`是赋值表达式，具有赋值结果；`a=3;`是表达式语句。课件原对照：

```cpp
int a;
(a=3)*10;    // 合法：a变成3，乘积为30，但30没有再保存
(a=3;)*10;   // 错误：普通括号内不能这样塞入带分号的语句
```

用分号结束表达式语句，不等于每行后都加分号。特别要分清：`if (...) ;`和`for (...) ;`可能意外控制一个空语句；`do ... while (...);`的末尾分号却是语法需要。

## 03｜流与输出：为什么可以连续写多个<<

**课件对应：P13—31，其中P14—27为连续栈演示。**

### 3.1 流的含义和连写原理

流可看成按顺序传递的数据序列。cin与cout是标准库对象，通过`<iostream>`使用，通常连接键盘和显示器，也可以重定向到文件等。C/C++核心语法没有单独的“输出语句”关键字，输入输出由标准库提供。

`<<`在整数操作中可表示左移，在cout操作中经重载成为流插入；`>>`类似。优先级和结合性仍遵守运算符规则。

课件原例：

```cpp
cout << a << b << endl;
```

分组是`((cout << a) << b) << endl`。每一步返回流本身的引用，因此下一步能继续使用它。

| 栈演示的核心阶段 | 动作 | 留下供下一步使用的结果 |
|---|---|---|
| 读cout、<<、a | 输出a | cout |
| 再读<<、b | 输出b | cout |
| 再读<<、endl | 输出换行并刷新流 | cout |
| 结束 | 符号栈清空 | 整个流表达式完成 |

课件把cout、a、b、endl放在“运算数栈”里手算，这是解释分组的模型，不要求实际编译器建立这两个栈。cin连续提取也使用同一个流对象继续操作。

### 3.2 输出数据和排版是两件事

四种课件原写法都输出`This is a C++ program.`并换行：

```cpp
cout << "This is a C++ program." << endl;
cout << "This is " << "a C++ " << "program." << endl;
cout << "This is "
     << "a C++ "
     << "program."
     << endl;
// 也可以拆成4条语句
cout << "This is ";
cout << "a C++ ";
cout << "program.";
cout << endl;
```

换行由输出内容决定，不由源代码换行决定。`cout << "hello\nhello" << endl;`输出两行hello。

课件原例`int a=10,b=15,c=20; cout << a << b << c;`输出`101520`。要空格就明确写`cout << a << ' ' << b << ' ' << c;`。

逗号不能替代插入运算符：

| 课件原式 | 解释/输出 |
|---|---|
| `cout << a,b,c;` | 等同`(cout<<a),b,c;`，只输出10 |
| `cout << (a,b,c);` | 括号内取最后的c，输出20 |
| `cout << (a,b,c) << endl;` | 输出20并换行 |
| `cout << a,b,c << endl;` | 后半部分试图计算`c<<endl`，不合法 |

课件P31：int ch=65输出65；char ch=65输出A。保持原变量类型不变时，int输出字符可写`cout << char(ch);`；char输出编码可写`cout << int(ch);`。不准强制转换时，可写`cout << ch+0;`，利用整型提升。

### 3.3 缓冲、换行和刷新

课件原例用Windows的`Sleep(1000*5)`与Linux的`sleep(5)`延时5秒，对比先输出`12345`、等待、再输出`abcde`。另一例先`cout.flush()`再等待，观察先前内容何时出现。Sleep单位为毫秒，sleep单位为秒，所需头文件分别为`<Windows.h>`与`<unistd.h>`，不是可随意互换的标准C++接口。

```cpp
cout << "12345";
cout.flush();     // 也可写 cout << flush;
// 此处等待5秒，再执行下一行
cout << "abcde" << endl;
```

**准确理解：**endl=换行并刷新；`'\n'`、`"\n"`只是写入换行，C++不保证它们总会刷新。终端、C/C++流同步、缓冲设置和平台可能让实际显示时机不同，不能据某次显示先后判定某操作系统“不符合规范”。

## 04｜输入：从缓冲区按类型提取数据

**课件对应：P32—36、P40—42。**

### 4.1 cin一次读取的是目标类型所需的数据

```cpp
cin >> a >> b >> c >> d;
// 可以跨行，也可以拆成四条cin语句
```

交互终端通常按回车后提交一行输入；流随后从输入序列中提取数据。**准确理解：**“按回车才能读到”主要是终端的行输入行为，不是cin对所有来源的固定要求；文件或重定向输入无需等人按回车。

课件原反例：`cin >> a,b,c;`只提取a，b和c不会因此被赋值。它在语法上可构成逗号表达式，编译器是否警告或后续报未初始化错误，要结合完整程序，不能说这条语句在所有编译器必然语法错。

`cin >> a+10;`不合法；分组相当于给临时计算结果输入，不能修改一个可用目标。`cin >> (a,b,c);`在a、b、c均为普通变量时，逗号表达式的结果指向c，所以只读c。输入`10 20 30`时c取得第一个数10，20与30留在输入序列中。

### 4.2 同样的输入，目标类型不同就读出不同内容

课件原例：

```cpp
char c1,c2;
int a;
float b;
cin >> c1 >> c2 >> a >> b;
cout << c1 << ' ' << c2 << ' ' << a << ' ' << b << endl;
```

输入`1234 56.78`或`1 2 34 56.78`，都得到c1='1'、c2='2'、a=34、b约56.78。char默认跳过前导空白后读一个字符；整数继续读34；float读56.78。

默认格式化提取跳过前导空格、制表符、换行。只输入空格或按回车，通常还会继续等待实际数据。要读取空白字符，可以使用getchar、cin.get等方法，不能说cin整个库“无法处理空格”。

输入char时不会执行C++源码里的转义解析：

| 课件键盘输入 | `cin >> ch`读取的第一个字符 | ASCII兼容环境的编码 |
|---|---|---|
| `abc` | a | 97 |
| `\n`（两个实际按键字符） | 反斜杠 | 92 |
| `'a'`（连单引号也输入） | 单引号 | 39 |

“字符型只能输入33—126”是课件的简化；实际按流和编码读取字节，并不限于这个范围，默认只是不把前导空白提取给char。

### 4.3 最长合法前缀和范围检查分开进行

课件原测试：

```cpp
short k;
cin >> k;
cout << "k=" << k << endl;
```

| 输入 | 读取过程/结果 |
|---|---|
| `123`后回车 | k=123 |
| `123 456` | k=123，456留给后面 |
| `-123m456` | k=-123，m及后续仍未读 |
| `m` | 没有整数前缀，提取失败 |
| `54321` | 整串都是十进制数码，但超16位short上限，失败 |
| `-40000` | 同理超下限，失败 |
| 只回车，或空格再回车 | 只有前导空白，通常继续等待 |

不会因为short装不下54321，就自动把它截成5432。“读合法数字序列”和“检查是否可表示”不是一件事。

课件用上一章转义例作对照：`"\23456f"`的八进制转义固定最多吞3个八进制数字，后面留下5、6、f，长度4；`"\43456f"`先吞434，值284超8位字符范围，应诊断，而不是退回只吞43。

### 4.4 多余输入留给后面，不是每条cin必须再敲一行

P42原例在四次cin前依次打印`--1--`至`--4--`。假设此前没有可用输入：

- 每次只输入1个数：四次都需等待输入。
- 每次输入2个数：第一次等待，第二次直接使用剩余数，第三次等待，第四次直接读取。
- 第一次输入4个以上：只有第一次需要等待，后3次直接取已有数据；多余数字及相关分隔字符没有被程序提取。程序结束后不应假定这些数据一定能传给另一个程序。

## 05｜输入错误、状态与后续读取

**课件对应：P35—46。**

### 5.1 先判断读取成功，再使用值

课件在输入后打印`cin.good()`与`cin.fail()`。good表示当前流无任何状态位；fail表示设置了failbit或badbit。更直接的成功判断是：

```cpp
int a=0;
if (cin >> a) {
    cout << a << endl;
} else {
    cout << "输入错误" << endl;
}
```

课件简化为“good=0时值不可信”。**准确理解：**good为false也可能只是成功读完最后一个数时设置了eofbit，未必说明本次数值错误；判断本次提取是否成功优先用`if(cin >> a)`或fail。上面的if已经引入一个后续章节要学的选择结构，先理解其意思即可。

课件short测试的典型观察：合法123、123空格456、-123m456得到good=1、fail=0；直接m或越界得到失败状态，可能打印0或边界值。不要把失败后打印的数当成成功输入，也不要读取根本未初始化的后续变量。

### 5.2 无符号输入不是自动拒绝负号

P39对unsigned short给出以下**课件环境观察值**：

| 输入 | 课件打印k | good/fail | 学习结论 |
|---|---|---|---|
| -65536 | 65535 | 0/1 | 失败，不能把此值当输入结果 |
| -65535 | 1 | 1/0 | 课件环境接受并按无符号规则转换 |
| -1234 | 64302 | 1/0 | 65536-1234 |
| -1 | 65535 | 1/0 | 与下一行数值相同，但状态不同 |
| 70000 | 65535 | 0/1 | 越界失败 |

无符号目标并不能替代“用户输入必须非负”的业务检查。负号处理细节与类型宽度、标准库实现有关，上表不能当所有平台的统一测试答案。

课件P40对比`short k; k=54321;`和`cin>>k`后输入54321：前者是整数类型转换，课件16位模型的位模式结果为-11215；70000转short为4464。后者是格式化数字提取并检查范围，失败状态不能按赋值转换规律解释。

浮点原测试`float f; cin >> f;`：123.456789得到近似值，默认打印可能为123.457；12e3为12000；1.2e40超常见float范围，检查失败状态。输出显示几位与内部有效精度分开理解。

### 5.3 课件八组连续输入：全部补齐

P43每次读一个整数后立即打印状态。失败后不清状态，后面的提取通常不再进行。以下只列成功得到的值，失败后的原程序变量不作有效数值使用：

| 原输入 | 成功读取 | 首次失败 |
|---|---|---|
| `1 2 3 4m` | a=1,b=2,c=3,d=4 | 四次都成功，m留着 |
| `1 2 3m 4` | a=1,b=2,c=3 | d遇m失败 |
| `1 2m 3 4` | a=1,b=2 | c遇m失败，d不再正常读取 |
| `1m 2 3 4` | a=1 | b失败，c/d不再正常读取 |
| `1 2 3 m` | a=1,b=2,c=3 | d失败 |
| `1 2 m 4` | a=1,b=2 | c失败，d不再正常读取 |
| `1 m 3 4` | a=1 | b失败，c/d不再正常读取 |
| `m 2 3 4` | 无 | a失败，后面均不正常读取 |

P44把四次读取写在同一行`cin>>a>>b>>c>>d;`，全部完成后才连续打印四次good。输入`1 2m 3 4`，四次看到的都是最终流状态0；这不表示先前a和b没有成功读入，状态没有保存每一步的历史。

补充恢复方式：先`cin.clear()`清除失败状态，再用`cin.ignore(numeric_limits<streamsize>::max(),'\n')`丢弃错误行，需要`<limits>`。只clear而不消费原来的非法字符，下次可能仍然在同一个字符失败。

### 5.4 Ctrl+C、Ctrl+Z：终端控制，不是普通数据

课件P45测试：Ctrl+C、`123`后直接Ctrl+C、`123 `后Ctrl+C、`123 456 `后Ctrl+C。通常Ctrl+C中断程序；已经发生的输出受执行时机影响，不为“中断之后”编造统一结果。

P46测试：Ctrl+Z、Ctrl+Z123、Ctrl+Z123空格456、123Ctrl+Z456、123空格456Ctrl+Z。Windows控制台常用Ctrl+Z配合回车表示EOF；行为与终端/运行环境相关。Linux终端EOF常用Ctrl+D，Ctrl+Z通常是挂起进程。课件P40把某处“输入结束”写为Ctrl+c应与后文区分理解，不把Ctrl+C当正常EOF使用。

| dec、hex、oct | 整数十/十六/八进制 | 持续到另一次同类设置 |

## 07｜字符输入输出与C方式输入输出

**课件对应：P50—54。**

### 7.1 putchar：输出字符，返回int

需要`<cstdio>`，也可在C方式用`<stdio.h>`。课件原例`putchar(a)`（a='A'）、`putchar('A')`、`putchar('\x41')`、`putchar('\101')`都输出A。

成功时返回输出字符对应的unsigned char值再转为int；失败时返回EOF。不能只记“永远返回ASCII码”，也别把返回值误认为char。

```cpp
char ret1;
cout << (ret1=putchar('A')) << endl; // 先输出A，ret1按char再输出A：AA
int ret2;
cout << (ret2=putchar('B')) << endl; // B后输出整数66：B66
```

课件证明返回类型的三种方法：

```cpp
cout << putchar('A') << endl;                   // A65
cout << sizeof(putchar('A')) << endl;           // 课件int大小4，不执行putchar
cout << typeid(putchar('A')).name() << endl;    // 观察int类型名，不执行该调用
```

sizeof通常不求值；这里typeid作用于int结果，也不会执行putchar。不能从“没有再次输出A”误判函数没作用。

### 7.2 getchar：取一个字节，返回int或EOF

课件两个原写法：`ch=getchar(); cout<<ch;`与`cout<<(ch=getchar());`，在char ch已定义且输入成功时等价，输入a都显示a。

不允许定义char变量却想显示字符，可写`putchar(getchar());`；严谨处理时先用int接返回值，判断是否EOF再输出。也可在已知成功时`cout<<char(getchar());`。

| 原键盘输入 | `cout<<getchar()`的典型结果 |
|---|---|
| 一个空格后回车 | 32 |
| 直接回车 | 10，即文本模式下常见的换行'\n' |
| 两个实际字符`\n` | 92，即反斜杠，n留着 |

getchar可以读空格和换行，也不会把键盘的反斜杠n翻译成换行。返回int是为了同时表示所有unsigned char字节值和EOF，所以判断输入结束前优先用int保存。

课件`--Step1--`至`--Step4--`连续四次getchar：每次只回车时每次需新输入；输入a后回车，第一次取a，下一次直接取尚未消费的换行；首次输入abcd后回车，前四次依次取a、b、c、d，换行还在。输入等待与回显主要取决于终端模式。

### 7.3 getchar、_getch、_getche比较

| 函数 | 课件控制台中的回显 | 是否通常需要回车 | 可移植性 |
|---|---|---|---|
| getchar | 有 | 是，终端行模式下 | 标准C/C++库 |
| _getche | 有 | 否 | 常见于Windows/conio.h环境 |
| _getch | 无 | 否 | 同上 |

课件在小熊猫/MinGW等环境观察到getch与_getch、getche与_getche两种名称可用；不能推广成所有gcc平台都有conio.h。测试时关闭中文输入法，避免把输入法行为与函数行为混在一起。

### 7.4 printf/scanf要看懂，但遵守作业要求

课件要求熟练cin/cout、能读懂printf/scanf；除明确要求外，C++作业不用printf/scanf。另发自学资料不在本PDF里，先记以下常见对应：

```cpp

double d;
char c;
scanf("%d", &a);
scanf("%lf", &d);       // double输入用%lf
scanf("%c", &c);        // %c默认不跳过空白
printf("%d %f %c\n",a,d,c);
```

课件C方式在VS下写`#define _CRT_SECURE_NO_WARNINGS`，这是编译器相关设置，不是C语言语法必须部分。使用所需标准头文件，不依赖“某编译器不加头文件也碰巧通过”。

课程另有明确格式要求：作业末尾不添加getchar、system("pause")、cin>>a等暂停语句。

## 08｜顺序程序：方程根与字母转换

**课件对应：P55—56。**

顺序结构的重点不是代码短，而是前一步为后一步提供正确数据，并明确计算前提。

### 8.1 课件原例：求一元二次方程的根

```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main()
{
    float a,b,c,x1,x2;
    cin >> a >> b >> c;
    x1=(-b+sqrt(b*b-4*a*c))/(2*a);
    x2=(-b-sqrt(b*b-4*a*c))/(2*a);
    cout << "x1=" << x1 << endl;
    cout << "x2=" << x2 << endl;
    return 0;
}
```

数学式：ax²+bx+c=0，判别式Δ=b²-4ac，根为(-b±√Δ)/(2a)。C++里平方写b*b，乘法必须明确写`*`，不能写b^2或4ac；整个分母2*a必须用括号括起。

例：输入`1 -3 2`，得到x1=2、x2=1。原程序默认a不为0且Δ≥0；Δ<0时实数sqrt不能得到实根，a=0时也不能直接套公式。原程序运行时没有提示文字，只会等输入，不代表“卡死”。

课件同时给出C版本：用double a,b,c,x1,x2；`scanf("%lf %lf %lf",&a,&b,&c);`输入；相同公式计算；`printf("x1=%f\n",x1);`和x2对应输出。完整原写法见P55附录。

### 8.2 课件原例：大写字母变小写

```cpp
char c1,c2;
cin >> c1;
c2=c1+32;
cout << c1 << ' ' << c2 << endl;
```

ASCII兼容编码下，大写A—Z与小写a—z相差32，更能体现含义的式子是`c2=c1+'a'-'A';`。课件还列`c1=getchar();`、`scanf("%c",&c1);`、`printf("%c %c",c1,c2);`作为不同输入输出方式的对应。

输入A输出`A a`。如果输入z，122+32超出有符号8位char正范围；转换后的字节与控制台编码决定显示，不能期待得到一个正确的小写字母。问题根源是前提“不保证输入大写字母”。学习if后可先检查`c1>='A' && c1<='Z'`。

## 09｜关系表达式：比较结果也有类型和值

**课件对应：P57—59、P65。**

关系运算符为`< <= > >= == !=`。前四个比==、!=结合得更紧；都低于算术运算，高于赋值。C++内建比较结果是bool，默认输出为0/1。

课件原例：`10+20>30`为false；`(a=20)>(b=30)`使a=20、b=30，再得到false。`int a=1,b=2,c; c=a>b;`使c=0，随后`c=a<b;`使c=1。

### 9.1 不能照搬数学中的连续比较

课件P58的两组原数据与全部结果：

| 原式 | a=1,b=2,c=3 | a=3,b=2,c=1 |
|---|---|---|
| `a>b>c` | `(0>3)`为0 | `(1>1)`为0 |
| `a<b<c` | `(1<3)`为1 | `(0<1)`为1 |
| `b>a<c` | `(1<3)`为1 | `(0<1)`为1 |

两组程序都得到0、1、1，这不代表数学意义的三者大小关系相同。C++先算左边比较，再拿bool的0/1与c比较。

数学a>b>c应写`a>b && b>c`。课件另一原陷阱`70<t<=80`会先得到70<t的0或1，再判断它是否≤80，结果几乎失去原意；正确是`t>70 && t<=80`。

### 9.2 比较结果可以继续参加算术

课件`10+(a<=b)*2`在条件真时为12，假时为10。`c=a>b`是赋值表达式，所赋内容来自比较结果。

`=`与`==`完全不同：a=10修改a，表达式结果关联a；a==10只比较。课件P65先写`int a; a==10;`用于讲区别，但若a还是未初始化局部变量，读取它本身有问题，实际练习应先给初值。

## 10｜浮点比较：精度、误差和输出位数

**课件对应：P60—64，与第02模块浮点存储衔接。**

### 10.1 十进制看起来不同，内部可能相同

课件原常量`123456.78901234567e5`和`123456.78901234568e5`在常见double格式下落到相同可表示值。double不是任意精度实数；binary64的52位小数域加隐含前导位，共通常53位二进制有效精度。

课件又复用100.25与-1.2：100.25能有限二进制展开，float位模式0x42C88000，可精确保存；-1.2的float位模式0xBF99999A，约为-1.2000000476837158203125。课件按高位到低位列`42 c8 80 00`及`bf 99 99 9a`；小端内存从低地址读取时顺序相反。

课件指出100.25从double转float被舍弃的小数域位都是0，而1.2含非零舍弃位，用来解释某些VS警告差异。是否警告由编译器设置决定，不作为精度正确性的证明。

### 10.2 课件两个比较原例

```cpp
float f1=100.25;
cout << (f1-100.25) << endl;  // 0
cout << (f1==100.25) << endl; // 1
float f2=1.2;
cout << (f2-1.2) << endl;     // 约4.76837e-08
cout << (f2==1.2) << endl;    // 0
```

右侧1.2默认double，与左侧float的近似值不同。若按本题容差判断，可写：

```cpp
cout << (fabs(f1-100.25)<1e-6) << endl; // 1
cout << (fabs(f2-1.2)<1e-6) << endl;    // 1
```

需要`<cmath>`。输出比较式必须把整个比较括起来，因为<<优先级高于<、==；否则可能被解析为拿流对象再作比较。

### 10.3 课件原精度对照：double与float

```cpp
double f1=123.456789012345678;
double f2=123.456789123456789;
cout << (f1==f2) << endl;             // 0
cout << (fabs(f1-f2)<1e-6) << endl;   // 1
cout << (fabs(f1-f2)<1e-7) << endl;   // 0

float g1=123.456789012345678;
float g2=123.456789123456789;
cout << (g1==g2) << endl;             // 1
cout << (fabs(g1-g2)<1e-6) << endl;   // 1
cout << (fabs(g1-g2)<1e-7) << endl;   // 1
```

差别在转float时已丢失，g1与g2保存成同一个值。fabs无法恢复原本不同、后来被舍入成相同的数据。

P64继续用fixed分别输出上述两数的double与float版本，setprecision(15)和setprecision(20)各一次，观察float相同而double仍可区分。打印更多位是暴露已存近似值，不能提高原始信息的精度。

**准确理解：**课件在作业中禁用浮点==是教学约束；C++语法允许==，在需要精确相等时也有用途。`fabs(a-b)<eps`是容差比较，不是适合所有数值尺度的保证；eps应来自问题要求，大数可能需要相对误差。不要把1e-6当成所有题目的万能阈值。

**参考答案10**

1. 不会，只改变显示精度参数。
2. 不能，差异已经在存储转换中丢失。
3. <<比<优先级高，需要明确先形成比较结果，再把结果交给cout。

## 11｜bool、逻辑运算、短路与位运算区别

**课件对应：P66—72。**

### 11.1 bool赋值不等于截取低字节

bool的值为true或false。课程环境sizeof(bool)=1，但一般标准不要求它永远是1字节。true与false默认输出1和0。

课件原赋值：k=123得到true；k=0得到false；k=256仍为true，不会因256的低8位是0而变false。规则是**非零变true，零变false**。`bool f=true; int a=10; a=a+f;`得到11。

课件sizeof测试：sizeof(bool)、sizeof(f)、sizeof(true)、sizeof(false)在课程环境均为1；sizeof("true")为5、sizeof("false")为6，后两者是带尾零的字符串字面量。

默认`cin>>bool`读取0或1：0、1成功；输入123通常置failbit；直接输入true或false在默认模式下也失败。课件观察输出依次为`1 0 0`、`1 1 1`、`0 1 1`、`0 0 0`、`0 0 0`（字段是good、bool值、转int的值）；失败后的值不当作有效输入。

补充：`cin>>boolalpha>>k;`可改为读true/false，输出流boolalpha可改为打印文字，故“只能输入0/1”应加“默认设置下”的条件。

课件标题“C++特有，C无”并不完整，P67已补充C可借助`<stdbool.h>`使用bool/true/false。P67所附C程序仍误用了cout，应改为printf，不能直接把该片段当正确C程序。

### 11.2 三种逻辑运算与真值表

| A | B | !A | A&&B | A或B（逻辑或） |
|---|---|---|---|---|
| 假 | 假 | 真 | 假 | 假 |
| 假 | 真 | 真 | 假 | 真 |
| 真 | 假 | 假 | 假 | 真 |
| 真 | 真 | 假 | 真 | 真 |

与用`&&`，或用`||`，非用`!`。作为逻辑条件时数值非零为真；逻辑运算的结果自身是bool，不会返回原来的4或5。优先级：!高于算术和比较；比较高于&&；&&高于||；逻辑运算高于赋值。

课件a=4,b=5的四个原式：a&&b=1；a||b=1；!a||b=1；!a&&b=0。`4&&0||2`为1。`5>3&&2||8<4-!0`为1，分组为`((5>3)&&2)||(8<(4-(!0)))`。

### 11.3 短路会改变哪些语句实际执行

内建&&：先算左边，左边假则右边不再计算。内建||：左边真则右边不再计算。因此上面的复杂原式在左侧已得到真时，不必执行`8<4-!0`。

课件原例：

```cpp
int a=1,b=2,c=3,d=4,m=1,n=1;
(m=a>b)&&(n=c>d);
cout << "m=" << m << " n=" << n << endl; // m=0 n=1
```

m被改为0后，右侧不求值，所以n维持1。`a&&b&&c`首项为0可跳过后两项；`a||b||c`首项非零可跳过后两项。

用于条件时，a==0可用!a表达，a!=0可直接用a作为条件；但若把表达式数值打印出来，a和a!=0并非总相等，例如a=5时前者5、后者1。

补充安全例：`k!=0 && n%k==0`能在k为0时跳过余数计算，顺序反过来就不能保护除零。

### 11.4 逻辑与/或不等于按位与/或

课件short a=3,b=4：

```text
a=...0011，b=...0100
a&&b → 1         a&b → 0
a||b → 1         a|b → 7
```

按位运算逐bit处理，且没有内建逻辑运算的短路保证；类型先进行整型提升/通常转换，不能只拿“两个字节直接画图”替代完整类型分析。其他位运算有^、~、<<、>>。课件要求本课程作业不用位运算；这里用来防止把&&、||误写成&、|。

## 12｜if三种形式与分数分级

**课件对应：P73—78。**

### 12.1 单分支、双分支、多分支

```cpp
if (条件) {
    条件为真时的语句;
}

if (条件) {
    真分支;
} else {
    假分支;
}

if (条件1) {
    分支1;
} else if (条件2) {
    分支2;
} else {
    都未命中时的分支;
}
```

条件按能转换为bool的规则判断，本章数值零为假、非零为真。原课件所说“任意类型”是简化，不代表任何对象都能无条件用作条件。

只有一条受控语句时可以省{}，但多条需要用块。条件括号内不是普通表达式语句，不能照抄成`if(表达式;)`；`if(条件);`虽然可能语法合法，却把空语句当作了受控体。

if与else之间不能插入一条独立的cout再指望else与前面的if配对。else是整个if结构的一部分，不是可以随意悬空的语句。

### 12.2 课件原例：同一条cout，花括号不同，效果不同

P74输入成绩i：

```cpp
if (i<60) {
    cout << "不及格" << endl;
}
cout << "程序结束" << endl;
```

输入37输出“不及格”“程序结束”；输入74只输出“程序结束”。如果把最后一条cout移进if块，37仍输出两行，74则两行都不输出。缩进不能改变花括号决定的控制范围。

P76的边界反例：`if(i<=60)`输出不及格，else输出及格，会把60误判；应改为`if(i<60)`。几个普通测试都通过不代表正确，要主动测试边界。

### 12.3 课件原例：完整成绩分级

```cpp
if (i>=90 && i<=100)
    cout << "优" << endl;
else if (i>=80 && i<90)
    cout << "良" << endl;
else if (i>=70 && i<80)
    cout << "中" << endl;
else if (i>=60 && i<70)
    cout << "及格" << endl;
else if (i>=0 && i<60)
    cout << "不及格" << endl;
else
    cout << "输入错误" << endl;
cout << "程序结束" << endl;
```

与课件实际代码一致：0—59不及格，60—69及格，70—79中，80—89良，90—100优。题干文字有时按另一顺序罗列等级，以代码与分数对应关系为准。

P78思考：对于整数，`i<90`和`i<=89`等价；允许小数时并不等价。把第二分支上界改成`i<=90`，在本例先检查90—100的前提下，90已被前分支截住，结果仍可正确，但分区表述不如无重叠的范围清晰；若重排分支，重叠又可能暴露错误。

## 13｜嵌套、else配对与条件运算符

**课件对应：P79—94，P80—91是括号配对连续演示。**

### 13.1 花括号按栈配对，else找最近可配对的if

遇左花括号入栈，遇右花括号与最近未配对的左花括号配对；不能交叉。原演示将花括号编号1—10，配对依次为2—3、4—5、1—6、8—9、7—10，最后栈空。

else与最近的、语法上允许匹配且尚未带else的if配对，花括号划定边界，缩进只是帮助人阅读。

```cpp
if (A)
    if (B)
        cout << "甲";
    else
        cout << "乙"; // 属于if(B)
```

若想让else属于if(A)，要明确写外层花括号，把内部if完整放进块中。

P92原嵌套用条件1/2/3及语句①—⑤描述路径：

```cpp
if (条件1) {
    if (条件2) {
        语句①;
    } else {
        语句②;
    }
    语句③;
} else {
    if (条件3) {
        语句④;
    }
    语句⑤;
}
```

①需条件1真且条件2真；②需1真2假；③只需1真；④需1假3真；⑤只需1假。一个块内部的if不能越过闭合花括号去抢外层else。

课件P93把成绩分级写成嵌套：先i>=80，内部i>=90分优/良；否则先i>=60，内部i>=70分中/及格，剩余不及格。假设输入在0—100。加全花括号后含义更容易看清，完整原printf写法在附录保留。

### 13.2 条件表达式：选择一个表达式的结果

形式`条件 ? 真时表达式 : 假时表达式`，右结合。只计算被选中的一个分支表达式，但两个分支在编译时都要满足相容等类型规则。

课件原例：

```cpp
max = a>b ? a : b;
cout << "max=" << (a>b ? a : b) << endl;
printf("max=%d",a>b ? a : b);
```

课件还把两条cout分别放到?:两臂：

```cpp
a>b ? cout << "max=" << a << endl
    : cout << "max=" << b << endl;
```

可以理解，但把公共输出写在外面更清楚。?:不只适用于赋值，只是入门常用来替代给同一变量赋不同值的if-else。

原类型对照：`a==1 ? "Hello" : 123`不相容；`a>b ? cout<<a : printf("%d",b)`的两臂为流引用与int，不相容；`a==1 ? 'A' : 123`合法，共同类型为int，真时值65，不一定按字符A输出。

## 14｜switch：离散值分支与贯穿

**课件对应：P95—99。**

### 14.1 switch从匹配标签进入，不会自动在下个case前停止

```cpp
switch (整数或枚举条件) {
case 常量1:
    语句1;
    break;
case 常量2:
    语句2;
    break;
default:
    无匹配时的语句;
    break;
}
```

case常量转换后不能重复，排列次序没有固定要求；可以多个case共用一组语句；default可省略且最多一个。没有break就会继续执行后面的语句，称为贯穿，不是再次匹配才执行。

条件应为整型、枚举或允许转换到这类类型的对象，不能直接switch(double)。课件`switch(int(x))`是先显式转换再分支，不是switch自动接收任意实数。

### 14.2 课件原例：按成绩十位分支

```cpp
switch (i/10) {
case 10:
case 9:
    cout << "优" << endl; break;
case 8:
    cout << "良" << endl; break;
case 7:
    cout << "中" << endl; break;
case 6:
    cout << "及格" << endl; break;
case 5: case 4: case 3: case 2: case 1: case 0:
    cout << "不及格" << endl; break;
default:
    cout << "输入错误" << endl; break;
}
```

这是课件P96待查错原例。整数输入-9到-1时除10向0截断为0，被误判不及格；101到109除10为10，被误判优。这两个非法区间说明：先按商分类，会丢失原范围信息。

P97的正确方向：先判断`i>=0 && i<=100`，再switch(i/10)。范围已保证后default可承接0—59，不用逐一写case 0—5；非法原输入在外层else处理。

### 14.3 课件case常量与break的对照

- const int k=1；case 3+7与case 8+k分别为10、9，合法。
- const int k=1；case 8与case 7+k都为8，重复标签，非法。
- int k=1；case 8+k不是要求的常量表达式，非法。
- case 8输出“良”但漏break，后面case 7输出“中”，则输入对应8时会同时打印良和中。
- case 8放到case 10/9前面也可以，顺序无需按数值排序。

P99原分段是0—59不及格、60—69及格、70—84良、85—100优。switch(score/10)不能区分84和85；直接switch(score)虽能枚举整数分值但冗长。此时if范围判断更自然，成绩允许小数时尤为如此。

## 15｜选择结构综合：闰年、椭圆塔、分班

**课件对应：P71、P100—105。**

### 15.1 闰年：把自然语言翻译成逻辑式

课件按公历规则：能被4整除但不能被100整除，或者能被400整除。

```cpp
bool leap=(year%4==0 && year%100!=0) || year%400==0;
```

课件P71全部等价写法保留如下（运算符优先级相同）：

```cpp
(year%4==0)&&(year%100!=0)||(year%4==0)&&(year%400==0)
(year%4==0)&&(year%100!=0)||(year%400==0)
(year%4==0)&&(year%100)||(year%400==0)
!(year%4)&&(year%100)||!(year%400)
!(year%4)&&year%100||!(year%400)
```

“不是闰年”原式为`year%4!=0 || (year%100==0 && year%400!=0)`，内部括号可因&&高于||而省略，但保留更容易读。

P100嵌套判断：若被4整除，再判断100；若也被100整除，再判断400；不被4整除为平年，不被100整除但被4整除为闰年。P101改为链式：

```cpp
if (year%4!=0) leap=false;
else if (year%100!=0) leap=true;
else if (year%400!=0) leap=false;
else leap=true;
```

再改为给leap直接赋逻辑式，即P102最简方向。四种写法判断规则一致。测试2000真、1900假、2024真、2023假，四类路径各覆盖一个。

原输出方式有if-else两条cout、两种printf，以及：

```cpp
cout << year << (leap ? "is" : "is not") << " a leap year." << endl;
printf("%d %s a leap year.\n",year,leap ? "is" : "is not");
printf("%d is%s a leap year.\n",year,leap ? "" : " not");
```

第一条原式缺年份后的空格，会成为`2024is...`。修正为`cout << year << (leap ? " is" : " is not") << " a leap year." << endl;`。保留原式便于识别输出细节错误。

### 15.2 四个椭圆塔：一项表示“在一个塔内”，或连接四项

题目原数据：圆心(5,5)、(-5,5)、(-5,-5)、(5,-5)，横向半轴3，纵向半轴2，塔高10m，其他地点0m，边界算塔内。

```cpp
double x,y;
cout << "请输入坐标：";
cin >> x >> y;
if (((x-5)*(x-5)/9+(y-5)*(y-5)/4<=1) ||
    ((x-5)*(x-5)/9+(y+5)*(y+5)/4<=1) ||
    ((x+5)*(x+5)/9+(y+5)*(y+5)/4<=1) ||
    ((x+5)*(x+5)/9+(y-5)*(y-5)/4<=1))
    cout << "高度为10" << endl;
else
    cout << "高度为0" << endl;
```

对中心(a,b)，判据为`(x-a)^2/9+(y-b)^2/4<=1`，源码要用乘法表达平方，不能使用^。用double避免坐标和除法被整数规则改变。复制四次时必须逐项检查±号；边界浮点误差是否加容差，取决于题目要求。

测试：(5,5)在塔中心，高10；(8,5)恰在边界，高10；(0,0)在塔外，高0。

### 15.3 n个人每班k人：商给完整班，余数决定补一个班

前提：n为非负整数，k为正整数。课件P104反例来自截图，关键代码转写如下：

```cpp
double o,p,m,b;
int c;
cin >> o >> p;
b=o/p;
c=o/p;
if (b-c>0) m=c+1;
else m=c;
cout << m;
```

原意o=n、p=k，b保存浮点商，c保存截断后的商，再比较是否有小数。**准确理解：**c=o/p本身仍做浮点除法，之后转int，不是直接做整数除法；这比课件旁注“c是整数除法”更精确。输入用浮点、结果m又用浮点都偏离计数语义；误差与越界也容易出问题。

P105全部原解法：

```cpp
// 1. if-else
if (n%k==0) cout << n/k << endl;
else cout << n/k+1 << endl;

// 2. 条件运算符的两种形式
cout << (n%k==0 ? n/k : n/k+1) << endl;
cout << (n/k+(n%k==0 ? 0 : 1)) << endl;

// 3. 利用关系/逻辑值的三种形式
cout << n/k+(n%k>0) << endl;
cout << n/k+bool(n%k) << endl;
cout << n/k+!!(n%k) << endl;

// 4. 不用if、?:、bool及关系/逻辑运算符
cout << (n+k-1)/k << endl;
```

例如n=100,k=30需要4班，90人需要3班，0人需要0班。`(n+k-1)/k`可能在加法时超出int范围；更稳妥的计数形式是`n/k+(n%k!=0)`。这些公式不能不加前提地用于负数或k=0。

## 16｜循环基础：goto、while与do-while

**课件对应：P106—114。**

### 16.1 循环要同时考虑四件事

```text
初值是什么？ → 什么条件继续？ → 一轮做什么？ → 怎样接近结束？
```

当型先判断，可能执行0次；先执行后判断的循环至少1次。课件把do-while称为“直到型”，但C++的尾部条件**为真继续，为假退出**，不能误套某些伪代码repeat-until的“条件真则退出”。

### 16.2 goto原例：为了读懂，不是推荐写法

课件原无限循环：

```cpp
LOOP:
cout << "Hello";
goto LOOP;
```

goto跳到同一函数中相应标签，容易使流程难跟踪。本课程明确禁止使用goto完成作业；这里记录原例用于阅读理解。

P108原求和逻辑有两种：

```cpp
// 先判断型
int i=1,sum=0;
LABEL1:
if (i<=100) {
    sum+=i;
    i++;
    goto LABEL1;
}

// 先执行后判断型：与上一段分开阅读，不可放在同一作用域重复标签
int i=1,sum=0;
LABEL1:
sum+=i;
i++;
if (i<=100) goto LABEL1;
```

原第二段有`int i=1; sum=0;`却没有声明sum的笔误，上面转写时已补正。流程图中若从i=0并判断i<100再先累加，会得到0+...+99=4950；要算1+...+100，调整初始化、判断或先自增的位置，不能只改一个数字就认为等价。

### 16.3 while：先看条件，再执行一轮

```cpp
int i=1,sum=0;
while (i<=100) {
    sum=sum+i;
    i++;
}
cout << "sum=" << sum << endl; // 5050
```

课件也写`while(i<=100) sum+=i++;`，先用本轮i相加，再递增。刚入第j轮时，i=j、sum为1到j-1之和，这一“不变量”能帮助检查逻辑。

课件原例“打印1—1000内7的倍数”两种算法：

```cpp
int i=1;
while (i<=1000) {
    if (i%7==0) cout << i << ' ';
    i++;
}
// 或直接生成满足条件的数
int i=7;
while (i<=1000) {
    cout << i << ' ';
    i+=7;
}
```

输出从7到994，共142个。第二种少做大量取余和筛选；两段作为独立方案阅读，不重复声明在同一作用域。

### 16.4 do-while：先执行一轮，再看是否继续

```cpp
int i=1,sum=0;
do {
    sum+=i;
    i++;
} while (i<=100);
cout << "sum=" << sum << endl;
```

P114把7倍数筛选也改成do形式，先i=1，每轮判断i%7，最后i++，尾部i<=1000。求和与倍数例在这些初始条件下都正确，但不代表任意初值下与while等价。

P114“直接加7”流程图一处把初值标为i=1，应按代码理解为i=7；否则会输出1、8、15……，不再是7的倍数。

**准确理解：**循环体未直接改变某个条件变量不一定死循环，输入、break等也可使它结束；反之只写了i++也不一定能保证正确终止，需要检查条件与数值范围。

## 17｜for的执行顺序、变形与空语句

**课件对应：P115—123。**

### 17.1 for不是按括号内从左到右反复执行全部三项

```cpp
for (表达式1; 表达式2; 表达式3) {
    循环体;
}
```

顺序：表达式1只执行一次 → 判断表达式2 → 真则循环体 → 表达式3 → 再判断2。2是假则结束，最后一次失败判断后不执行体和3。

课件求1到100的和：

```cpp
int i,sum=0;
for (i=1;i<=100;i++)
    sum=sum+i;
cout << "sum=" << sum << endl; // 5050
```

基本while改写为“先1；while(2){循环体；3;}”。**有continue时不能机械这样改**，见下一块；for初始化声明的变量作用域也要保留。

### 17.2 课件原例：一直累加到超过10000

```cpp
int i,sum;
for (i=1,sum=0;sum<=10000;i++)
    sum+=i;
--i;
cout << "i=" << i << " sum=" << sum << endl;
```

条件实际是“sum尚未超过10000就继续”，因此最终sum**超过**10000，不是恰好10000。1到140的和9870；加141后为10011，随后i++到142，下一次条件失败，--i回141。输出`i=141 sum=10011`。

课件while版本`while(sum<=10000) sum+=i++; --i;`同理。如果题目要“和不超过10000的最大前缀”，应在加下一项前判断sum+i是否超过，不能直接套原结果。

### 17.3 原课件的for变形逐一保留

以下均假定sum已有合适初值，分别是不同方案：

```cpp
i=1;
for (;i<=100;i++) sum+=i;       // 初值放前面
for (i=1;i<=100;) sum+=i++;     // 增量放循环体
for (i=0;i++<100;) sum+=i;      // 判断用旧i，循环体用递增后的i
for (i=0;++i<=100;) sum+=i;     // 判断和循环体都用新i
i=1;
for (;i<=100;) { sum+=i; i++; } // 类似while
for (;;) { /* 自行安排退出条件 */ }
while (1) { /* 同样可由break退出 */ }
```

省略条件表达式表示真，不必然是无法终止的“死循环”；循环内可以break或return。两个分号不能省。含i++的两种变形都能加1—100，退出时i通常为101，务必逐次模拟。

课件用逗号把多项放在1或3中：

```cpp
for (i=1,sum=0;i<=100;sum=sum+i,i++)
    ;
for (i=1,sum=0;i<=100;sum=sum+i++)
    ;
for (i=1,sum=0;i<=100;sum+=i++)
    ;
cout << "sum=" << sum << endl;
```

这里空语句是有意的，累加放在表达式3里。P122原对照：若for后面有分号，cout是循环外只输出一次5050；没有分号时，紧跟的cout成为循环体，每轮先输出当前sum，再在表达式3累加。因此可看到0、1、3……4950共100次输出，而不是最后只输出5050。缩进不改变这一点。

### 17.4 用输入作为条件、输出作为更新

课件P123原式：

```cpp
char c;
for (;(c=getchar())!='\n';cout<<c)
    ;
```

等价思路：先读c，若不是换行就输出，再读下一个。它在正常输入一行的前提下回显到换行之前；若输入EOF但没有换行，原式没有检查EOF，可能无法正确结束。

补充更稳妥形式：

```cpp
int c;
while ((c=getchar())!=EOF && c!='\n')
    putchar(c);
```

原课件还展示C++11范围for：`array<int,5> arr={6,7,4,5,2}; for(auto &it:arr){cout<<typeid(it).name()<<endl; cout<<it<<endl;}`。顺序访问6、7、4、5、2，类型名依实现；课程暂不要求掌握STL且禁止在作业中使用相关容器，作为后续知识导览。

## 18｜嵌套循环、break与continue

**课件对应：P124—132。**

### 18.1 嵌套看层次，不只看花括号是否成对

while内while、for内for、for内while、do内do等都可以。每次进入外层的一轮，会从头执行遇到的内层循环；内层可能执行0次，也可能提前退出。分支和循环可以嵌套，但括号正确只是语法的一部分，不能据此保证算法正确。

P124示意中的`do(...)`应理解为图示笔误；C++正确语法是`do { ... } while(...);`，do后无条件括号。

课件原双循环：

```cpp
for (i=1;i<=100;i++)
    for (j=1;j<=100;j++)
        cout << i*j << ' ';
```

cout执行10000次。P125三层原例：

```cpp
for (i=1;i<=100;i++) {
    cout << i << endl;              // 100次
    for (j=1;j<=100;j++) {
        cout << i*j << endl;        // 10000次
        for (k=1;k<=100;k++)
            cout << i*j*k << ' ';   // 1000000次
        cout << j*i << endl;        // 10000次，处于k循环外
    }
    cout << i << endl;              // 100次
}
```

“for j执行100遍”通常指内层循环整体被进入100次；其条件测试次数、循环体总执行次数是另一个数量。不要把这些统计对象混在一起。

### 18.2 break：离开最近的循环或switch

课件P126同一个超过10000例改成：

```cpp
for (i=1,sum=0;;i++) {
    sum+=i;
    if (sum>10000) break;
}
// i=141，sum=10011，不需要--i
```

break发生在最后一次i++之前，所以i仍为141。另一原变形：`while(1){sum+=i++; if(sum>10000) break;} i--;`，由于i++在加法处已经执行，仍需减回一次。这是两种写法的重要差别。

多层循环中break只跳出最近一层；循环里面有switch时，位于switch内的break只结束switch；switch里面有for时，for内部的break只结束for，之后仍会继续case后面的语句。break不是退出整个程序，return才离开当前函数。

### 18.3 continue：跳过本轮剩余部分

| 所在循环 | continue之后去哪里 |
|---|---|
| while | 重新判断条件 |
| do-while | 到尾部判断条件 |
| for | 先执行表达式3，再判断表达式2 |

课件“必须和if/else一起使用”应理解为常见用法，而非语法强制要求；无条件break或continue本身也可以合法。

原7倍数continue方案1：

```cpp
int i=1;
while (i<=1000) {
    if (i%7!=0) {
        i++;
        continue;
    }
    cout << i << ' ';
    i++;
}
```

两条路径都要自增，否则遇第一个非7倍数就可能停在同一个i。课件指出该写法只为演示，逻辑偏绕。

原方案2、3：

```cpp
int i=0;
while (++i<=1000) {
    if (i%7!=0) continue;
    cout << i << ' ';
}
// 或
for (int i=1;i<=1000;i++) {
    if (i%7!=0) continue;
    cout << i << ' ';
}
```

若在for中的switch某case里写continue，它针对外层最近循环，不是针对switch。若没有任何外层循环，switch内单独continue非法。

### 18.4 课件break/continue结果对照

```cpp
int i=0,sum=0;
while (i<1000) {
    i++;
    break;       // 与下一题的continue互换作比较
    sum+=i;
}
cout << "i=" << i << " sum=" << sum << endl;
```

break版本i=1,sum=0；改continue后i=1000,sum=0；sum+=i都不会被执行。课件P132输出链中`<<sum; <<endl;`多了一个分号，上面已修正输出语句；先修语法再谈运行结果。

## 19｜循环求π：精度、速度与无法终止

**课件对应：P133—134。**

### 19.1 原公式与状态变量

课件原公式：π/4=1-1/3+1/5-1/7+……，目标按某项绝对值阈值停止。

| 变量 | 课件初值 | 每轮作用 |
|---|---|---|
| s | int 1 | 分子的正负号，每轮取负 |
| n | double 1 | 奇数分母，每轮加2 |
| t | double 1 | 当前项s/n |
| pi | double 0 | 暂存π/4的累加和，结束后乘4 |

原核心：

```cpp
while (fabs(t)>1e-7) {
    pi=pi+t;
    n=n+2;
    s=-s;
    t=s/n;
}
pi=pi*4;
```

前几轮：加1，准备-1/3；加-1/3，准备1/5；加1/5，准备-1/7。n必须能支持非整数除法，若误改为整数s/n，n>1后的项可能直接变0。

注意题干“最后一项<阈值”与程序细节：循环是在**加当前项之前**检查，所以首次达到阈值以下的待加项不会进入和；退出时n表示下一项的分母，不是最后已加项的分母。严格不等号和≤号的边界也要明确。

### 19.2 可直接运行的主体：沿用原算法，清楚命名阈值

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;
int main()
{
    const double eps=1e-7;
    int s=1;
    double n=1,t=1,pi=0;
    while (fabs(t)>eps) {
        pi+=t;
        n+=2;
        s=-s;
        t=s/n;
    }
    pi*=4;
    cout << "n=" << setprecision(10) << n << endl;
    cout << "pi=" << fixed << setprecision(9) << pi << endl;
    return 0;
}
```

这是说明性整理版，原P134仍保留于附录。级数收敛很慢，阈值缩小10倍通常要多做约10倍迭代。理想精确算术下，π/4的交错级数截断误差不超过首个未加项绝对值；π本身需再乘4，同时实际浮点运算还会累积舍入误差。因此“项<1e-7”不等于“π绝对误差一定<1e-7”。

### 19.3 课件原计时程序的三个Windows调用

```cpp
LARGE_INTEGER tick,begin,end;
QueryPerformanceFrequency(&tick);
QueryPerformanceCounter(&begin);
// 中间执行上面的循环
QueryPerformanceCounter(&end);
double seconds=(end.QuadPart-begin.QuadPart)/double(tick.QuadPart);
```

需要`<windows.h>`，频率单位Hz，计数差除频率得到秒。课件完整程序打印n、9位小数pi、频率、计数差和6位小数时间。不要漏除法中的double转换，否则整数相除可能丢掉小数秒。

课件实验要求保留：double版本对比1e-6、1e-7、1e-8、1e-9；再把n/t/pi改float，对比1e-6、1e-7，并思考1e-8为何无结果。时间由机器、构建配置和运行情况决定，本笔记不编造固定运行时间。

### 19.4 float版本为什么可能不终止？

binary32有效精度有限。n不断加2，达到某个数量级后，相邻可表示数间距已大于2；在常见舍入到最近值规则下，n到33554432=2²⁵时，n+2可能又舍入回原n。分母不再增加，|t|停在约2.98×10⁻⁸，大于1e-8，条件一直为真。

这时仅改成“显示更多位”无济于事；循环不结束不是电脑太慢，而是浮点状态停止前进。根据设计应选择足够精度或整数计数器，并结合算法误差需求设计终止条件。

## 20｜斐波那契与素数：状态更新和提前退出

**课件对应：P135—136。**

### 20.1 斐波那契前40项：两个变量交替推进

课件约定F1=1,F2=1，后项为前两项之和。原程序：

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main()
{
    int i,f1=1,f2=1;
    for (i=1;i<=20;i++) {
        cout << setw(12) << f1 << setw(12) << f2;
        if (i%2==0) cout << endl;
        f1=f1+f2;
        f2=f1+f2;
    }
    return 0;
}
```

每轮输出2个数，20轮输出40个；每2轮换行，即每行4个，setw要给两个输出分别设置。

| 一轮开始时(f1,f2) | 输出 | 更新f1后 | 再更新f2后 |
|---|---|---|---|
| (1,1) | 1,1 | (2,1) | (2,3) |
| (2,3) | 2,3 | (5,3) | (5,8) |
| (5,8) | 5,8 | (13,8) | (13,21) |

第二条更新用的是**已经更新的新f1**，所以一次推进两项。不能把它误当同时赋值。第40项为102334155，原程序最后还会继续更新到F41与F42，二者在32位int内仍可表示。扩展项数要考虑后续更新是否会有符号溢出。

原例局限是只保留最近两个状态，覆盖后无法直接取出早先任意一项；后续学数组可以保存全部项。这里不是“数列无法重算”，而是原程序没有存储历史。

### 20.2 素数：没有发现除数，才可认定通过

课件任务：找出100—200之间全部素数。素数指大于1、仅有1和自身两个正因数的整数。若合数有因子分解m=a*b，则至少一个因子≤√m；因此试除到√m就足够。

区间内不需要测偶数，原外层为`m=101;m<=200;m+=2`。课件第一版算法核心：

```cpp
prime=true;
k=int(sqrt(m));
for (i=2;i<=k;i++)
    if (m%i==0) {
        prime=false;
        break;
    }
```

找到**任意一个**除数就可退出并判非素数；没有在第一个i找到除数，不意味着已经是素数。prime必须每个新m开始时重置为true。

课件的等价变形：`for(i=2;prime && i<=k;i++) if(m%i==0) prime=false;`，下一次条件通过prime使循环结束，也能表达提前停止。

### 20.3 原程序换行位置的错误与修正版

课件第一版把`if(line%10==0) cout<<endl;`放在if(prime)外面。当line已经是10或20，后续合数虽然没输出也会再次触发换行，造成额外空行；课件建议把范围改为103—200观察差异；起点改变会改变第10个、第20个素数出现的位置，从而暴露后续合数上的重复换行。若另改成从合数起步，line最初为0也可能触发多余换行。正确做法是只在输出一个素数且计数递增后判断换行。

课件原程序漏列sqrt需要的`<cmath>`，以下整理版补上，并沿用“每10个素数换行”：

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;
int main()
{
    int line=0;
    for (int m=101;m<=200;m+=2) {
        bool prime=true;
        int k=int(sqrt(m));
        for (int i=2;i<=k;i++) {
            if (m%i==0) {
                prime=false;
                break;
            }
        }
        if (prime) {
            cout << setw(5) << m;
            line++;
            if (line%10==0) cout << endl;
        }
    }
    if (line%10!=0) cout << endl;
    return 0;
}
```

预期21个素数：

```text
101 103 107 109 113 127 131 137 139 149
151 157 163 167 173 179 181 191 193 197
199
```

### 20.4 不用prime，利用循环退出原因

课件第二版核心：

```cpp
k=int(sqrt(m));
for (i=2;i<=k;i++)
    if (m%i==0) break;
if (i>k) {
    cout << setw(5) << m;
    line++;
    if (line%10==0) cout << endl;
}
```

退出只有两类：因找到因子break，此时i≤k，非素数；正常走完，此时i>k，素数。这里i要在for外先声明，因为后面还要使用它。该思路在本题m≥101时清楚成立，扩展为通用判素数程序需另行处理m<2。

### 自测20

1. 原斐波那契程序一轮为何推进两项，而不是重复算同一项？

3. 素数循环正常退出时i>k，break退出时为何i≤k？

## 综合练习参考答案

### 1. 三种输出

依次只输出10；只输出20；输出101520。它们作为独立表达式比较；若不加分隔并连续运行，会连在一起。

### 2. 按类型读取

c1='1'、c2='2'、a=34、b为56.78的double近似。目标类型决定读取边界。

### 3. 失败状态不保存每步历史

a=1、b=2成功；c在m处失败；d没有正常提取。后面的good都查询到已经失败的流状态。这里把四个变量初始化为0，避免原课件未初始化变量的额外问题；不能因为c/d碰巧为0就说它们成功读到了0。

### 4. 区间条件

`(x>70 && x<=80) || x==100`。错误连写会先算70<x为0/1，再判断这个0/1是否≤80。

### 5. 短路赋值

第一组m=0,n=1；第二组m=2,n=1。&&左假跳过右；||左真跳过右。注意m保存2，但整个逻辑或结果是true。

### 6. 合法区间先于十位分类

```cpp
if (score<0 || score>100) {
    cout << "输入错误" << endl;
} else {
    switch (score/10) {
    case 10: case 9: cout << "优" << endl; break;
    case 8: cout << "良" << endl; break;
    case 7: cout << "中" << endl; break;
    case 6: cout << "及格" << endl; break;
    default: cout << "不及格" << endl; break;
    }
}
```

### 7. 分班公式

`n%k==0 ? n/k : n/k+1`；`n/k+(n%k!=0)`；`(n+k-1)/k`。第三种n+k-1可能超类型范围。

### 8. for执行顺序

第一段不输出，sum=6，i=4。第二段输出`0 1 3 `，最后sum=6，i=4；因为每轮先输出当前sum，再在表达式3中累加与递增。

### 9. 保留continue的更新路径

```cpp
i=1;
while (i<=5) {
    if (i==3) {
        i++;
        continue;
    }
    cout << i;
    i++;
}
```

输出1245。若只把i++放在while体末尾，i==3时会被continue跳过，形成死循环。

### 10. 输入、生成、计数、格式化、累加综合

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main()
{
    int N;
    if (!(cin>>N) || N<1 || N>10000) {
        cout << "输入错误" << endl;
        return 0;
    }
    int count=0,sum=0;
    for (int i=7;i<=N;i+=7) {
        cout << setw(6) << i;
        count++;
        sum+=i;
        if (count%10==0) cout << endl;
    }
    if (count%10!=0) cout << endl;
    cout << "sum=" << sum << endl;
    return 0;
}
```

N=20时输出7、14及sum=21。N<7但仍为合法正整数时没有倍数，直接输出sum=0。上界10000使本题和能容纳在32位int内；程序按格式化整数提取规则读N，若业务还要求整行除空白外不得有额外字符，需要另加整行校验。

|---|---|
| 三个数输出粘在一起 | cout不自动插空格 |

| 两个小数比较“反常” | 先检查存储类型和舍入，再选误差模型 |
| 区间连写a<x<b | C++逐次比较，应用&& |
| if多一个分号 | 可能变成控制空语句 |
| else配错 | 看花括号与最近可匹配if，不看缩进 |
| switch把105当优 | 先验证原始范围，再按商分类 |
| case后漏break | 发生贯穿 |
| for正常结束i多1 | 最后一轮之后执行了表达式3 |
