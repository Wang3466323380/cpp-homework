# VS 多源文件与头文件

一个 C++ 项目可以由多个 `.cpp` 组成。**每个 `.cpp` 分别编译，再把结果链接成一个程序。** 函数声明让编译器知道怎么调用，函数定义提供实际要运行的代码。

## 1. 在 Visual Studio 中建立多源文件项目

1. 在同一个项目下，右键「源文件」→「添加」→「新建项」，建立 `main.cpp`、`sub.cpp` 等文件。已有的文件用「添加」→「现有项」加入项目。
2. 有自定义头文件时，在「头文件」中添加 `.h`，在用到它的 `.cpp` 中写 `#include "文件名.h"`。
3. 一个可执行项目里保留一个 `main()`。其他 `.cpp` 定义辅助函数。生成项目时，把这些 `.cpp` 一起编译和链接。

**解决方案可以包含多个项目。** 作业中的 `4-b14` 到 `4-b17` 各生成一个 exe，所以它们可以各有一个 `main()` 和一套同名函数。

## 2. 声明、定义与调用

| 写法 | 在做什么 |
|---|---|
| `int twice(int n);` | 声明函数。参数名 `n` 可以省略，参数类型要写 |
| `int twice(int n) { return 2 * n; }` | 定义函数，写出函数体 |
| `twice(3)` | 调用函数，把 `3` 传给它 |

调用前要能看到声明。声明和定义的返回类型、函数名、参数类型和顺序要一致。普通函数的定义放进一个 `.cpp` 就够了。

下面三个文件放在同一个项目，运行会输出 `6`。

**`calc.h`**

```cpp
#pragma once

int twice(int n);
```

**`calc.cpp`**

```cpp
#include "calc.h"

int twice(int n)
{
    return 2 * n;
}
```

**`main.cpp`**

```cpp
#include <iostream>
#include "calc.h"

int main()
{
    std::cout << twice(3) << '\n';
    return 0;
}
```

如果题目要求不使用自定义头文件，把 `int twice(int n);` 直接写在 `main.cpp` 的 `main()` 前面，去掉两个源文件里的 `#include "calc.h"`，再将两个 `.cpp` 加入同一个项目。多个文件都要调用时，将声明集中放进一个头文件，函数签名改动时只需维护一份声明。定义函数的 `.cpp` 也包含同一个头文件，便于编译器检查声明和定义是否一致。

## 3. 头文件放什么

| 内容 | 常见写法和用途 |
|---|---|
| 函数声明 | `void shi(double a, double b, double gen);`，供多个源文件调用 |
| 类型声明或定义 | `struct`、`class`，课件列为后续内容 |
| `inline` 函数定义 | 把函数体放在头文件里，各使用它的 `.cpp` 包含同一份定义 |
| 宏和常量 | `#define PI 3.14159` 是宏替换，`const int max_count = 10;` 有整数类型 |
| 全局变量声明 | `extern int count;`，变量本身在一个 `.cpp` 中定义 |
| 依赖的头文件 | 头文件里若用到其他头文件提供的类型，就包含对应头文件 |

`#include` 可以理解成把头文件的内容放到这一行。**`#pragma once` 让同一个头文件在每个 `.cpp` 的编译过程中只处理一次。** 把它放在头文件开头，学号、姓名、班级的注释可以放在它前面。

也正因为每个 `.cpp` 都各自处理头文件，把普通全局变量定义 `int count = 0;` 写进头文件，两个 `.cpp` 包含它后就各有一份定义，链接时报重复定义。加了 `#pragma once`，每个 `.cpp` 仍然会各处理一次。

> 各文件直接包含自己需要的库头文件即可。公共头文件里通常也避免写 `using namespace std;`，因为它会影响每个包含该头文件的源文件。

## 4. 用 `extern` 共享全局变量

```cpp
// main.cpp，在函数外定义一次
double a, b, c;

// sub.cpp，声明要使用同一组变量
extern double a, b, c;
```

- 同类型的变量可以写在同一条 `extern` 声明里，声明的类型要与定义匹配。有多个文件需要共享时，可以把 `extern` 声明集中写进头文件。
- `main()` 里直接写 `std::cin >> a >> b >> c;`。如果又在函数里写一遍 `double a, b, c;`，输入就会存进局部变量。
- `main()` 里的 `gen` 仍然是局部变量。第 17 题要求四个函数无参，所以 `shi()` 和 `xu()` 可以用共享的 `a、b、c` 各自计算所需的值。

## 5. 双引号和尖括号

- `#include "calc.h"` 用于项目自己的头文件。以课程演示为例，编译器先在包含它的文件所在目录附近找，再查配置的包含目录。
- `#include <iostream>`、`#include <cmath>` 通常用于标准库，按编译器配置的包含路径查找。视频演示了双引号写成 `"iostream"` 时，同目录下一个恰好同名的空文件会被优先找到。
- C 用 `<math.h>`，例如 `sqrt(9.0)`。C++ 一般用 `<cmath>` 和 `std::sqrt(9.0)`。C++ 也可使用兼容的 `<math.h>`。

## 6. 对照第 14～17 题

| 题号 | 代码怎么放 |
|---|---|
| 14 | 一个 `4-b14.cpp`，包含 `main()` 和四个辅助函数 |
| 15 | `main.cpp` 写四个声明，`sub.cpp` 写四个定义 |
| 16 | `4-b16.h` 写四个声明，`main.cpp` 包含它，四个 `sub*.cpp` 各定义一个函数 |
| 17 | 两个 `.cpp`，`main.cpp` 定义 `a、b、c`，`sub.cpp` 写 `extern`，四个函数均无参 |

**遇到报错怎么找**

- **找不到函数名**，先检查调用前有没有声明，以及有没有包含对应的头文件。
- **LNK2019，无法解析的外部符号**，检查定义所在的 `.cpp` 是否加入项目，也检查声明和定义的参数类型是否一致。
- **LNK2005，重复定义**，检查是否把普通函数体或普通全局变量定义写进了被多个文件包含的头文件，或者在多个 `.cpp` 中各定义了一次。

同一项目中的两个文件可以共用一个函数，做法是**定义一次，多处声明**。如果有两个不同的函数要用同一个名字，可以用不同参数重载，或分别定义成文件内使用的 `static` 函数。重载既可写在同一个 `.cpp`，也可分在多个 `.cpp`，调用处要能看到参与选择的声明。
