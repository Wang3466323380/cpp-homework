# 重载函数与默认参数

**函数重载**让同一个名字对应多个函数，编译器根据实参选其中一个。**默认参数**让调用时可以少写末尾几个实参，编译器使用声明里指定的默认值。

## 1. 函数重载

同一作用域里，同名函数的参数个数、类型或类型顺序可以不同。比如这三个版本都叫 `my_max`，实现的都是求最大值。

```cpp
int my_max(int x, int y);
double my_max(double x, double y);
int my_max(int x, int y, int z);
```

- 只改参数名，仍然是同一个函数的声明。例如 `int f(int x);` 和 `int f(int n);` 可以同时写，函数体只定义一次。
- 只改返回类型不能形成重载。例如 `int f(int);` 和 `double f(int);` 放在一起会报错。
- 重载可以都定义在同一个 `.cpp`，也可以分在同一项目的多个 `.cpp`。调用处需要看得到要参与选择的声明，可以把它们一起放进头文件。
- C++ 支持这种函数重载，C 语言通常用不同函数名区分不同参数类型。

## 2. 编译器怎么选重载

先看实参数量和类型能匹配哪些版本，再比较各参数需要的转换。常见的优先顺序是**类型匹配 → 提升 → 其他标准转换 → 用户定义转换**。例如 `short` 转 `int`、`float` 转 `double` 属于提升。用户定义转换留到后续课程。

假设调用处能看到第 1 节的三个声明：

| 调用 | 编译器的选择 |
|---|---|
| `my_max(10, 15)` | 两个实参都是 `int`，选两参数的 `int` 版本 |
| `my_max(10.2, 15.3)` | 两个实参都是 `double`，选 `double` 版本 |
| `my_max(10, 15, 12)` | 三个实参，选三参数的 `int` 版本 |
| `my_max(10, 15.3)` | 两个版本各有一个参数匹配得更好，无法选出唯一最佳版本，报二义性 |
| `my_max(10, int(15.3))` | 调用前先把 `15.3` 转成 `15`，传入两个 `int` |
| `my_max(double(10), 15.3)` | 调用前先把 `10` 转成 `double`，保留小数 `15.3` |

以 `my_max(10, 15.3)` 为例，`int` 版本的第一个参数正好匹配，`double` 版本的第二个参数正好匹配。编译器不会因为你打算把结果存到 `double` 变量里，就替你选 `double` 版本。显式转换前先想清楚要保留小数，还是要按整数计算。

## 3. 默认参数怎么写

课件用画圆举例。圆心必填，半径、颜色、是否填充可以有默认值。

```cpp
void circle(int x, int y, int r = 10, int color = 7, bool filled = false);
```

| 调用 | 实际传入的参数 |
|---|---|
| `circle(15, 20)` | `15, 20, 10, 7, false` |
| `circle(15, 20, 8)` | `15, 20, 8, 7, false` |
| `circle(15, 20, 10, 1)` | `15, 20, 10, 1, false` |
| `circle(15, 20, 10, 7, true)` | `15, 20, 10, 7, true` |

- **只省略末尾的实参。** 想改颜色又想用默认半径，也要把半径 `10` 写出来。C++ 不能用空逗号跳过中间参数。
- **默认值放在末尾连续的几个形参上。** 例如 `void f(int x, int y = 0, int z = 5);` 可以，`void f(int x = 0, int y, int z = 5);` 会报错。
- **默认值要在调用前可见。** 声明写在头文件时，把默认值写在头文件的声明中，`.cpp` 里的定义只写形参，避免重复指定默认值。声明已经写了 `r = 10`，定义里即使再写同一个 `10` 也会报错。

像课件的 `circle` 那样，在末尾增加一个带默认值的 `filled`，旧的调用写法编译后就会自动补上 `false`。

## 4. 重载和默认参数一起用的陷阱

```cpp
int fun(int a);
int fun(int a, int b = 10);
```

- `fun(10, 20)` 只有第二个版本能接收两个实参，调用成立。
- `fun(50)` 两个版本都能接收一个实参。第二个版本可以补上默认的 `10`，第一个参数的匹配又一样好，所以会报二义性。

如果只需要一种补值规则，可以保留一个 `int fun(int a, int b = 10);`。如果确实要保留两个版本，就去掉第二个版本的默认值，让一个实参和两个实参各对应一个版本。

## 5. 可以直接运行的小例子

```cpp
#include <iostream>

int my_max(int x, int y)
{
    return x > y ? x : y;
}

double my_max(double x, double y)
{
    return x > y ? x : y;
}

int add(int x, int y = 10);

int main()
{
    std::cout << my_max(10, 15) << '\n';      // 15
    std::cout << my_max(10.2, 15.3) << '\n';  // 15.3
    std::cout << add(5) << '\n';              // 15
    std::cout << add(5, 2) << '\n';           // 7
    return 0;
}

int add(int x, int y)
{
    return x + y;
}
```
