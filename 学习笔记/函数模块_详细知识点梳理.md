## 二、为什么要有函数（第1—2页）

函数把一个相对独立的任务封装起来。调用者只需要知道输入什么、得到什么，不必每次重写内部过程。

例如，求四个数的最大值，可以建立在“求两个数最大值”的基础上：

```cpp
#include <iostream>

int max2(int x, int y)
{
    return x > y ? x : y;
}

int max4(int a, int b, int c, int d)
{
    return max2(max2(a, b), max2(c, d));
}

int main()
{
    std::cout << max4(3, 12, 7, 5) << '\n'; // 12
    return 0;
}
```

这里的好处包括：

- **复用**：`max2` 可以在多个位置使用。
- **分解**：`max4` 的思路变成“左右各比较一次，再比较两个结果”。
- **维护**：修改一个功能时，可以集中修改对应函数。
- **验证**：可以先检查小函数，再检查组合起来的程序。

普通 C/C++ 函数应当平行定义，可以相互调用，不能把一个普通函数的定义写进另一个函数体内。C++ 的 lambda 是另外一种机制，不属于这里讨论的普通函数定义。

对于本课程的普通控制台完整程序，保留一个 `main` 作为入口即可。工程中的库文件本身可以没有 `main`。

## 三、函数的定义、声明与调用（第3—6、18—28页）

### 3.1 函数定义的结构

```cpp
返回类型 函数名(形参列表)
{
    // 局部变量、计算过程
    return 返回表达式;
}
```

例如：

```cpp
double average(int a, int b)
{
    return (static_cast<double>(a) + b) / 2.0;
}
```

- `double`：函数调用产生的结果类型。
- `average`：函数名。
- `a`、`b`：接收输入的形式参数。
- `return`：结束本次调用，将结果交回调用处。

这里先把 `a` 转成 `double`，也避免了先做整数加法可能产生的溢出；`/ 2.0` 表示浮点除法。

### 3.2 按参数和返回值划分

| 类型 | 示例 | 典型用途 |
|---|---|---|
| 无参、有返回值 | `int read_number()` | 获取一个输入或结果 |
| 有参、有返回值 | `int max2(int a, int b)` | 根据输入进行计算 |
| 无参、无返回值 | `void print_menu()` | 显示固定菜单 |
| 有参、无返回值 | `void print_line(int n)` | 根据参数执行输出等操作 |

`void` 表示没有返回值，不表示函数没有功能。

```cpp
#include <iostream>

void print_line(int n)
{
    for (int i = 0; i < n; ++i)
        std::cout << '*';
    std::cout << '\n';
}

int main()
{
    print_line(5); // 输出 *****
    return 0;
}
```

### 3.3 声明、定义、调用一定要分清

```cpp
int max2(int a, int b);          // 声明：告知接口，以分号结束

int max2(int a, int b)           // 定义：提供实现
{
    return a > b ? a : b;
}

// 放在某个函数体内：
// int result = max2(3, 8);     // 调用：实际执行
```

调用时只写函数名和实参，不写返回类型，也不写实参类型：

```cpp
int result = max2(3, 8);       // 正确
// result = int max2(3, 8);   // 错误
// result = max2(int 3, int 8);// 错误
```

对于无参函数，调用写 `f()`，不能写 `f(void)`。

### 3.4 为什么“先调用，后定义”需要声明

编译器检查调用时，需要知道函数的返回类型以及参数的数量和类型。

```cpp
#include <iostream>

int square(int n); // 先声明

int main()
{
    std::cout << square(6) << '\n'; // 36
    return 0;
}

int square(int n)
{
    return n * n;
}
```

如果把完整定义放到 `main` 前，该定义已经提供了声明信息，可以不再单独写声明。

声明里的参数名可以省略，也可以与定义中的参数名不同：

```cpp
int square(int);
// 与 int square(int number); 描述同一个接口。
```

声明的作用范围也有边界：写在文件作用域的声明，供其后可见位置使用；写在函数体内的声明，名字的可见范围受所在代码块限制。实际组织代码时，通常把公共函数声明放在头文件中。

### 3.5 库函数与头文件

| 功能 | C 头文件 | C++ 常用头文件及写法 |
|---|---|---|
| 输入输出 | `<stdio.h>` | `<cstdio>`，如 `std::printf` |
| 数学运算 | `<math.h>` | `<cmath>`，如 `std::sqrt` |
| 字符串处理 | `<string.h>` | `<cstring>`，如 `std::strlen` |

**直接使用某个接口，就显式包含它对应的头文件。** 不应依赖其他头文件间接包含它，也不应依赖某个编译器恰好允许省略。

### 3.6 C 与 C++ 的无参声明差异

- C++ 中，`int f();` 和 `int f(void);` 都表示无参数。
- C17 及更早的 C 中，单独的声明 `int f();` 不提供参数数量和类型信息；`int f(void);` 才明确表示无参数。
- 因此，学习 C 时建议明确写 `f(void)`。调用仍然写 `f()`。

## 四、函数调用怎样执行（第7—8、19—24页）

### 4.1 嵌套调用的执行顺序

```cpp
#include <iostream>

void b()
{
    std::cout << "B\n";
}

void a()
{
    std::cout << "A begin\n";
    b();
    std::cout << "A end\n";
}

int main()
{
    std::cout << "main begin\n";
    a();
    std::cout << "main end\n";
    return 0;
}
```

输出：

```text
main begin
A begin
B
A end
main end
```

调用路径是 `main → a → b`；返回路径是 `b → a → main`。

可以用**调用栈**理解：后进入的函数先返回。每层调用需要保留返回位置，以及继续计算所需的状态。实际机器实现可能使用寄存器、栈，也可能被编译器内联优化；调用栈首先是理解执行过程的模型。

### 4.2 调用的三种常见位置

```cpp
print_line(5);                      // 单独作为语句
int result = max2(3, 8) + 2;         // 参与表达式
std::cout << max2(3, 8) << '\n';    // 结果用于后续输出
```

有返回值的函数也可以只作为语句调用，此时返回结果被丢弃。`void` 函数没有可用于加法、赋给整数等操作的结果。

### 4.3 不要依赖多个实参的求值顺序

避免写：

```cpp
// f(i++, i);
```

在 C++17 中，各参数求值之间有相应的顺序约束，但先算哪一个仍不确定；在 C 及较早版本的 C++ 中，这种读写组合还可能构成未定义行为。

把意图写清楚：

```cpp
int first = i;
++i;
f(first, i);
```

即使是 `f(i++, --j)` 这种操作不同变量的情况，也应分别算清两个表达式产生的实参值；不要把书写顺序当成确定的执行顺序。

## 五、形参与实参：理解“传值”（第9—12页）

### 5.1 两个名字的含义

```cpp
int square(int n) // n 是形参
{
    return n * n;
}

// int x = 5;
// int y = square(x); // x 是实参
```

实参可以是变量、常量或表达式，例如 `square(x)`、`square(5)`、`square(x + 1)`。

### 5.2 普通值参数获得的是副本

```cpp
#include <iostream>

void change(int x)
{
    x = 100;
    std::cout << "inside: " << x << '\n';
}

int main()
{
    int x = 10;
    change(x);
    std::cout << "outside: " << x << '\n';
    return 0;
}
```

输出：

```text
inside: 100
outside: 10
```

调用时可以近似理解为：**用实参的值初始化形参**。两个 `x` 是不同对象，形参修改后不会自动写回实参。同名不代表同一个变量。

### 5.3 想用计算结果更新原变量，可以接收返回值

```cpp
int changed(int x)
{
    return x + 1;
}

// int a = 10;
// a = changed(a); // a 变成 11，原因是调用后的赋值
```

`changed(a);` 和 `a = changed(a);` 的效果不同：前者丢弃结果，后者把结果写入 `a`。

### 5.4 拓展：通过引用或指针修改调用者对象

C++ 可以使用引用参数：

```cpp
void swap_ref(int& a, int& b)
{
    int temp = a;
    a = b;
    b = temp;
}

// int x = 3, y = 8;
// swap_ref(x, y); // x = 8，y = 3
```

这里的 `a`、`b` 引用调用者的对象，因此不适用“普通值参数修改不影响实参”的结论。

C 中可以传入地址：

```c
void swap_ptr(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

/* int x = 3, y = 8; */
/* swap_ptr(&x, &y); */
```

指针本身仍然按值传递，但指针副本指向原对象，通过解引用可以修改该对象。本例要求传入有效地址。

### 5.5 参数类型不完全相同，不一定报错

例如，`double` 实参传给 `int` 形参时可能发生隐式转换，小数部分会被截去：

```cpp
int identity(int x)
{
    return x;
}

// identity(3.9) 得到 3。
```

课件用 `70000` 转成 `short` 说明信息丢失。应掌握的是：**窄化转换可能丢失信息，具体结果不能脱离类型位宽、标准版本和实现讨论。** 不应把某台机器上的 `4464` 当成所有环境的固定答案。

## 六、返回值与 return（第13—17页）

### 6.1 return 同时完成两件事

1. 结束当前这一层函数调用。
2. 对有返回值函数，把表达式转换成函数返回类型，交给调用处。

```cpp
int classify(int x)
{
    if (x > 0)
        return 1;
    if (x < 0)
        return -1;
    return 0;
}
```

一个函数中可以写多个 `return`，但某一层调用执行到其中一个后就结束，不会继续执行其后语句。

### 6.2 返回类型可能导致数据转换

```cpp
int value()
{
    return 3.9;
}

// double d = value(); // d 是 3.0，而不是 3.9
```

过程是：`3.9 → int 类型的 3 → double 类型的 3.0`。后续用更宽的类型接收，不能恢复之前已经丢掉的信息。

### 6.3 void 函数可以提前结束

```cpp
void print_positive(int n)
{
    if (n <= 0)
        return;
    std::cout << n << '\n';
}
```

无返回值时写 `return;`，也可以自然执行到函数末尾。不要写 `return 0;`。

### 6.4 有返回值函数要覆盖所有正常出口

```cpp
int max2(int a, int b)
{
    if (a > b)
        return a;
    return b;
}
```

比“只在某个分支里返回”的写法更容易检查。编译器是否发出警告、警告是否被当成错误，取决于工具和选项，不能只靠“能编译”判断函数正确。

在 C++ 中，普通有返回值函数执行到末尾通常属于未定义行为，`main` 有特殊规则：执行到末尾等价于 `return 0;`。初学时仍建议显式写出。

`main` 的返回值交给程序启动环境，用于表示程序退出状态；`0` 表示成功。它与屏幕上输出的数字不是同一回事。

### 6.5 拓展：一次返回多个数据

“一个 return 返回一个值”不意味着只能返回一个数字。一个结构体值可以包含多个成员：

```cpp
struct DivisionResult {
    int quotient;
    int remainder;
};

DivisionResult divide(int a, int b)
{
    return {a / b, a % b};
}

// 前提：b 非零，且商可由 int 表示。
// auto r = divide(17, 5);
// r.quotient 是 3，r.remainder 是 2。
```

## 七、函数组合的实际应用（第29—31页）

### 7.1 判断素数

素数是大于 1、且正因数只有 1 和自身的整数。必须先处理 `n < 2`。

```cpp
bool is_prime(int n)
{
    if (n < 2)
        return false;

    for (int d = 2; d <= n / d; ++d) {
        if (n % d == 0)
            return false;
    }
    return true;
}
```

为什么只试到平方根？若 `n = a * b`，且两个因子都大于 `sqrt(n)`，乘积就会大于 `n`。因此，合数必有不大于平方根的因子。

这里用 `d <= n / d` 表达平方根边界，避免写 `d * d <= n` 时乘法可能溢出，也不需要浮点运算。

建议用以下数据检查边界：

| 输入 | 预期 | 检查目的 |
|---|---|---|
| -3、0、1 | false | 非素数定义域 |
| 2、3 | true | 最小素数 |
| 4、9、25 | false | 平方根边界 |
| 17 | true | 普通素数 |

**课件勘误：**第30页的版本未排除 `1`，会把 `1` 判成素数；第31页又把返回判断写成了 `i < k`，在刚好于平方根处找到因子时也会误判。应避免直接照抄。

### 7.2 枚举偶数的素数分解

```cpp
#include <iostream>

bool is_prime(int n)
{
    if (n < 2)
        return false;
    for (int d = 2; d <= n / d; ++d)
        if (n % d == 0)
            return false;
    return true;
}

void print_prime_pairs(int even)
{
    if (even < 4 || even % 2 != 0) {
        std::cout << "Please enter an even integer >= 4.\n";
        return;
    }

    for (int x = 2; x <= even / 2; ++x) {
        if (is_prime(x) && is_prime(even - x))
            std::cout << x << " + " << even - x
                      << " = " << even << '\n';
    }
}

int main()
{
    print_prime_pairs(20);
    return 0;
}
```

输出：

```text
3 + 17 = 20
7 + 13 = 20
```

只枚举到一半，是为了不重复输出 `17 + 3`。从 `2` 开始也能覆盖 `4 = 2 + 2`。找到第一组就 `break`，则只输出一组。

这里是在检查给定输入的分解情况；检查若干输入不构成对猜想的一般性证明。

## 八、递归：写法与阅读方法（第32—64页）

### 8.1 递归是什么

函数直接调用自己，或通过其他函数间接调用自己，叫递归。

`max2(max2(a, b), c)` 只是把内层调用结果作为外层实参。若 `max2` 函数体没有直接或间接调用自身，它就不是递归函数。

写递归要明确：

1. **终止条件**：哪个简单情况可以直接求解？
2. **递归关系**：当前问题与较小问题是什么关系？
3. **趋近终止的保证**：每一步是否最终能到达终止条件？

只有 `if` 不足以保证终止；参数变化必须让问题最终可解。

### 8.2 年龄问题

第一位学生10岁，后面每位比前一位大2岁：

```cpp
// 前提：n >= 1。
int age(int n)
{
    if (n == 1)
        return 10;
    return age(n - 1) + 2;
}
```

调用 `age(5)`：

```text
向下调用：age(5) → age(4) → age(3) → age(2) → age(1)
向上返回：   18  ←   16   ←   14   ←   12   ←   10
```

编写时先假设 `age(n - 1)` 已能正确算出，再考虑当前层如何利用它。阅读时则逐层记录调用和返回。

拓展：这个问题存在直接公式 `10 + 2 * (n - 1)`。递归适合展示关系，但并非总是最高效的实现。

### 8.3 阶乘：递归与循环

```cpp
// 为方便讨论，限定输入 0 <= n <= 20。
unsigned long long factorial_recursive(unsigned n)
{
    if (n <= 1)
        return 1;
    return n * factorial_recursive(n - 1);
}

unsigned long long factorial_loop(unsigned n)
{
    unsigned long long result = 1;
    for (unsigned i = 2; i <= n; ++i)
        result *= i;
    return result;
}
```

`factorial_recursive(4)` 的计算过程：

```text
f(4) 等待 4 * f(3)
f(3) 等待 3 * f(2)
f(2) 等待 2 * f(1)
f(1) 返回 1
f(2) 返回 2
f(3) 返回 6
f(4) 返回 24
```

每一层都有自己的参数 `n`。下层返回后，上层仍然保留自己的 `n`，继续完成乘法。

| 实现 | 时间复杂度 | 通常的额外空间 |
|---|---|---|
| 循环 | O(n) | O(1) |
| 递归 | O(n) | O(n) 调用栈 |

类型容量有限，递归与循环都无法绕过数值溢出。限定到 `20!` 可保证上述结果适合至少64位的 `unsigned long long`。

### 8.4 输出写在递归调用前后，结果不同

```cpp
void before(int n)
{
    if (n == 0)
        return;
    std::cout << n << ' ';
    before(n - 1);
}

void after(int n)
{
    if (n == 0)
        return;
    after(n - 1);
    std::cout << n << ' ';
}
```

在 `n >= 0` 的前提下：

- `before(3)` 输出 `3 2 1`：进入当前层就输出。
- `after(3)` 输出 `1 2 3`：下层返回后才输出。

### 8.5 课件字符输出题详解（第49—62页）

```cpp
void f(int n, char ch)
{
    if (n == 0)
        return;
    if (n > 1)
        f(n - 2, ch);
    else
        f(n + 1, ch);
    std::cout << char(ch + n);
}
```

调用 `f(7, 'k')` 时：

```text
进入各层的 n：7 → 5 → 3 → 1 → 2 → 0
执行输出的 n：                  2 → 1 → 3 → 5 → 7
```

在通常的 ASCII 兼容字符编码下：

| 返回到的层 | 表达式 | 字符 |
|---|---|---|
| n = 2 | `'k' + 2` | m |
| n = 1 | `'k' + 1` | l |
| n = 3 | `'k' + 3` | n |
| n = 5 | `'k' + 5` | p |
| n = 7 | `'k' + 7` | r |

最终输出 **`mlnpr`**。

注意，`n = 1` 时虽然参数先增到 `2`，下一步却会到 `0`，因此此输入仍然终止。不能只看某一步增大就认定无限递归。

### 8.6 进制转换（第63页）

```cpp
// 前提：n >= 0，2 <= base <= 10。
void print_base(int n, int base)
{
    if (n >= base)
        print_base(n / base, base);
    std::cout << n % base;
}
```

`print_base(14, 2)`：

```text
调用：14 → 7 → 3 → 1
返回时依次输出：1、1、1、0
结果：1110
```

整数除法去掉最低位，取余获得最低位。先递归处理高位，再输出当前最低位，就得到正常书写顺序。`n = 0` 时也会输出 `0`。

若扩展到16进制，应通过 `"0123456789ABCDEF"` 把余数映射成字符，不能直接输出余数10、11等十进制数字。

### 8.7 汉诺塔（第35页，补充实现）

把 `n` 个盘从源柱移到目标柱，分成三步：

1. 把上面的 `n - 1` 个盘移到辅助柱。
2. 把最大的盘移到目标柱。
3. 把辅助柱的 `n - 1` 个盘移到目标柱。

```cpp
// 前提：n >= 0。
void hanoi(int n, char from, char auxiliary, char to)
{
    if (n == 0)
        return;
    hanoi(n - 1, from, to, auxiliary);
    std::cout << from << " -> " << to << '\n';
    hanoi(n - 1, auxiliary, from, to);
}

// hanoi(3, 'A', 'B', 'C');
```

移动次数满足 `T(n) = 2T(n - 1) + 1`，得到 `2^n - 1`。总工作量是指数级，最大递归深度却是线性的；总调用次数和最大栈深度是不同概念。

### 8.8 无限递归与栈溢出（第64页）

如果递归不断产生新调用而不返回，通常会耗尽调用栈空间。栈帧大小、编译模式、平台和优化都会影响表现，不存在统一的“最多递归多少次”。

实际解决问题时优先检查终止条件、参数变化和输入范围。不能把“增大栈”作为修复错误递归的主要办法；尾调用优化也不是 C++ 必须提供的保证。

## 九、局部变量、全局变量与名字遮蔽（第65—75页）

### 9.1 局部变量的可见范围由代码结构决定

```cpp
void demo()
{
    int a = 10;
    {
        int b = 20;
        std::cout << a + b << '\n'; // 30
    }
    // std::cout << b; // 错误：b 已超出作用域
}
```

更准确地说，普通块内变量的作用域从声明位置开始，延伸到所在块结束。不是只要写在函数里，就能在整个函数任意位置使用。

函数调用关系不会扩展局部名字的可见范围：`main` 调用 `f`，不代表 `f` 可以直接使用 `main` 中的局部变量名。需要通过参数等明确渠道传递数据。

### 9.2 递归各层有独立的普通局部变量

```cpp
void show(int n)
{
    int x = 10;
    ++x;
    std::cout << n << ": " << x << '\n';
    if (n > 0)
        show(n - 1);
}
```

`show(3)` 输出：

```text
3: 11
2: 11
1: 11
0: 11
```

不是 `11、12、13、14`，因为每层都创建并初始化了自己的 `x`。

### 9.3 同名变量：内层名字遮蔽外层名字

```cpp
int value = 100;

void demo()
{
    int value = 20;
    {
        int value = 3;
        std::cout << value << '\n'; // 3
    }
    std::cout << value << '\n';     // 20
    std::cout << ::value << '\n';   // 100，C++全局作用域限定
}
```

遮蔽只影响名字查找，不会把外层对象删除，也不会改变外层值。不同层使用不同名字通常更清晰。

### 9.4 全局变量是共享状态

全局变量在函数外定义。多个函数访问同一个对象时，一处修改会影响后续访问。它与同名值参数的副本完全不同。

应优先通过参数和返回值传递数据，减少隐藏依赖。课件第74页提出本课程原则上禁用全局变量，这是课程作业约束，不是 C/C++ 语法限制；具体作业仍以教师要求为准。

## 十、存储类别：普通局部、static、extern（第76—87页）

### 10.1 普通局部变量与静态局部变量

```cpp
#include <iostream>

void normal_counter()
{
    int count = 0;
    std::cout << ++count << '\n';
}

void static_counter()
{
    static int count = 0;
    std::cout << ++count << '\n';
}

int main()
{
    normal_counter(); // 1
    normal_counter(); // 1
    static_counter(); // 1
    static_counter(); // 2
    static_counter(); // 3
    return 0;
}
```

| 特征 | 普通局部变量 | 静态局部变量 |
|---|---|---|
| 声明示例 | `int x = 0;` | `static int x = 0;` |
| 生存期 | 当前块的本次执行期间 | 整个程序执行期间 |
| 初始化效果 | 每次执行到定义时重新初始化 | 初始化一次，后续保留状态 |
| 名字作用域 | 所在块 | 所在块 |
| 未显式初始化的整数 | 值不确定，不能直接读取使用 | 零初始化 |

**static 延长生存期，不会把局部名字变成全局名字。** 函数返回后对象仍存在，函数外仍不能直接通过该局部名字访问它。

初始化时机需要细分：C++ 静态局部对象具有静态存储期；常量初始化可能在程序启动阶段完成，需要动态初始化的块内静态对象则在首次执行经过其声明时初始化。不要把所有情况都理解为“第一次调用才分配内存”。

### 10.2 课件中的 static“阶乘”陷阱（第78页）

```cpp
int f(int n)
{
    static int product = 1;
    return product *= n;
}
```

依次调用 `f(1)、f(2)、f(3)、f(4)、f(5)`，会得到 `1、2、6、24、120`。

但它不是通用阶乘函数：结果依赖历史调用。若首次调用就是 `f(5)`，结果是 `5`；再调用 `f(3)`，结果是 `15`。

如果移除 `static`，每次 `product` 都重新初始化成1，返回的就是 `n`。两种写法都不能代替一个对任意合法输入独立求阶乘的函数。

### 10.3 extern：声明其他地方定义的对象

```cpp
extern int total; // 声明已有对象，不在这里定义它
```

典型多文件结构：

```cpp
// shared.h
#ifndef SHARED_H
#define SHARED_H
extern int total;
void add_one();
#endif
```

```cpp
// shared.cpp
#include "shared.h"
int total = 0; // 唯一的定义

void add_one()
{
    ++total;
}
```

```cpp
// main.cpp
#include <iostream>
#include "shared.h"

int main()
{
    add_one();
    std::cout << total << '\n'; // 1
    return 0;
}
```

必须把两个 `.cpp` 一起编译、链接；不能只编译 `main.cpp`。

`extern` 不会让原本被 `static` 限制为内部链接的对象突然跨文件共享。它也不是修改作用域和生存期的一般开关。

### 10.4 静态全局变量：文件内部使用

```cpp
// a.cpp
static int count = 0;

// b.cpp 中可以另有 static int count = 0;
// 它们是互不相关的两个对象。
```

文件作用域的 `static` 主要改变的是**链接性**。普通全局变量与静态全局变量本来都具有静态存储期。

### 10.5 register：了解历史即可

课件第80页的 `register` 是历史上的寄存器存储建议，不保证对象真的放在寄存器中。C++17 已移除其作为存储类说明符的用法。学习现代 C++ 时不需要用它优化普通局部变量，应交由编译器优化。

## 十一、作用域、生存期、链接性必须分开（第88—90页）

| 概念 | 回答的问题 | 例子 |
|---|---|---|
| 类型 | 数据具有什么表示、取值和操作规则？ | `int`、`double` |
| 作用域 | 这段代码中，名字能否被查找到？ | 局部名字受代码块限制 |
| 生存期 | 对象在什么时间段存在？ | 静态局部对象在函数返回后仍存在 |
| 链接性 | 不同位置的声明能否表示同一实体？ | 两个文件通过 `extern` 引用同一全局对象 |

常见对象对照：

| 声明位置和形式 | 名字作用域 | 存储期 | 链接性 |
|---|---|---|---|
| 块内 `int x;` | 所在块 | 自动 | 无链接 |
| 值参数 `int x` | 对应函数定义的参数作用域 | 自动 | 无链接 |
| 块内 `static int x;` | 所在块 | 静态 | 无链接 |
| 文件作用域 `int x = 0;` | 从声明处起的文件/命名空间作用域 | 静态 | 通常外部链接 |
| 文件作用域 `static int x;` | 从声明处起的文件/命名空间作用域 | 静态 | 内部链接 |

**跨文件可共享，不意味着另一个文件无需声明就能使用该名字。** 链接性解决“是否同一个实体”，可见声明解决“编译器是否知道这个名字”。

课件的“代码区、静态区、动态区、寄存器”可作为常见实现模型，但语言标准不要求所有实现都采用相同布局。也不要把自动存储期等同于动态内存分配：普通局部变量与 `new`/`malloc` 申请的对象属于不同机制。

## 十二、变量的声明与定义（第92页）

```cpp
int number = 0;            // 定义，同时也是声明
extern int other_number;  // 声明，不是定义
extern int third = 3;     // 有初始化，是定义（文件作用域示例）
```

“声明”是更广的概念。定义通常提供对象本体或函数实现，而非定义声明只是提供相关信息。

对本模块普通的、具有外部链接的非 inline 全局变量，通常采用“**一个 `.cpp` 定义，头文件中 `extern` 声明**”的组织方式。不要把 `int number = 0;` 放入被多个 `.cpp` 包含的普通头文件，否则通常导致重复定义。

补充区别：C 文件作用域的 `int x;` 有“暂定定义”规则，不能把所有 C++ 多文件结论不加区分地套到 C。初学时使用明确的一处初始化定义，最容易保持结构清晰。

## 十三、内部函数与外部函数（第93—95页）

### 13.1 内部函数

```cpp
// tools.cpp
static int helper(int n)
{
    return n * n;
}

int calculate(int n)
{
    return helper(n) + 1;
}
```

`helper` 具有内部链接，其他源文件不能通过另写同名外部声明来链接到它。其他文件可以定义自己独立的同名内部函数。

为保持清晰，内部函数的前置声明和定义都显式写 `static`，并保持一致。

### 13.2 外部函数

```cpp
// tools.h
#ifndef TOOLS_H
#define TOOLS_H
int calculate(int n);
#endif
```

```cpp
// main.cpp
#include <iostream>
#include "tools.h"

int main()
{
    std::cout << calculate(4) << '\n'; // 17
    return 0;
}
```

把 `tools.cpp` 和 `main.cpp` 一起编译链接即可。普通非成员函数默认通常具有外部链接，函数声明中的 `extern` 一般可以省略。

区分两类错误：

- **编译阶段错误**：当前文件没有可见声明，编译器不知道函数接口。
- **链接阶段错误**：调用处有声明，但程序没有对应定义；或提供了多个不允许重复的外部定义。

声明不是实现。仅写 `int calculate(int);` 不会自动产生函数代码。

## 十四、课件中需要辨析的表述

| 课件相关内容 | 更准确的理解 |
|---|---|
| C 默认函数返回类型为 int（第4、6页） | 属于旧式 C 背景；C99 起不再支持隐式 int。现代 C/C++ 都应明确写返回类型。 |
| iostream 默认包含 cmath，或部分头文件可省略（第4、25页） | 不能依赖。使用数学函数应显式包含 `<cmath>`。 |
| 所有参数都是单向传值（第9—12页） | 适用于本节普通值参数；C++ 引用参数需要单独理解。 |
| 实参形参类型必须一致（第12页） | 许多不一致的类型允许转换，但可能丢失信息；应关注接口和转换是否合理。 |
| short 转换后固定得到4464（第12—13页） | 是特定实现背景下的结果，不是脱离类型位宽和标准版本的普遍规律。 |
| void 只能出现在逗号表达式等特定形式（第14页） | 课件是针对当前常见运算的简化说明；例如 C++ 还允许 `return void_function();` 出现在 void 函数中。初学重点是 void 没有可供数值运算的结果。 |
| 少写 return，一定由某编译器报某种错（第14—17页） | 诊断受版本、选项影响；应先按语言规则确保正常出口有返回值。 |

| static 局部变量第一次调用时才分配和初始化（第77页） | 应区分静态存储期、常量初始化和首次经过声明时的动态初始化。 |
| 常量或 const 变量都在静态区（第89页） | 不成立；局部 `const int x = 3;` 通常仍具有自动存储期。const 主要约束修改能力。 |
| 全局变量用下划线开头命名（第91页） | C/C++ 有保留标识符规则。建议使用 `g_count` 等普通前缀，避免双下划线和其他保留形式。 |

课件中的编译器截图可以帮助理解当时环境，但复习时应把“语言规则”“常见实现”和“课程要求”分开记忆。

## 十五、做题时的操作方法

### 15.1 阅读普通函数题

1. 找到 `main`，确认初值。
2. 遇到调用，先算各实参值。
3. 为当前调用建立独立的形参和普通局部变量记录。
4. 执行到 `return`，确定返回值及其类型转换。
5. 回到调用处，检查是否接收返回值。
6. 继续执行，注意全局变量和 static 对象的历史状态。

### 15.2 阅读递归题

建议手工建立这样的表：

| 调用层 | 参数 | 当前层局部值 | 等待下层后还要做什么 |
|---|---|---|---|
| 第1层 | n = 3 | x = … | 输出/乘法/下一次调用 |
| 第2层 | n = 2 | x = … | 输出/乘法/下一次调用 |
| 第3层 | n = 1 | x = … | 直接返回或继续 |

先画调用链，再从最深层逐层返回，逐条执行“调用之后的语句”。不要一开始就凭直觉拼输出。

### 15.3 编写函数前明确接口

以素数函数为例：

- 输入：一个 `int`。
- 输出：是否为素数。
- 边界：负数、0、1 都返回 false。
- 副作用：无须修改外部变量，无须在内部输出。

让计算函数负责计算、调用者负责输入输出，可以更方便复用。例如同一个 `is_prime` 能用于筛选区间素数，也能用于枚举素数对。

## 十六、自测练习与参考答案

### 练习1：传值与返回值

```cpp
int f(int x)
{
    x += 5;
    return x;
}

// int a = 3;
// f(a);
// std::cout << a << '\n';
// a = f(a);
// std::cout << a << '\n';
```

**答案：**先输出3，再输出8。第一次结果被丢弃；第二次通过赋值更新 `a`。

### 练习2：static 与自动变量

```cpp
void f()
{
    int a = 0;
    static int b = 0;
    std::cout << ++a << ' ' << ++b << '\n';
}
```

连续调用三次的答案：

```text
1 1
1 2
1 3
```

### 练习3：递归调用前后都有输出

```cpp
void f(int n)
{
    if (n == 0)
        return;
    std::cout << n << ' ';
    f(n - 1);
    std::cout << n << ' ';
}
```

`f(3)` 的答案：`3 2 1 1 2 3`。

### 练习4：补全最大公约数函数（拓展）

对于非负整数且不同时为0的 `a`、`b`：

```cpp
int gcd(int a, int b)
{
    if (b == 0)
        return a;
    return gcd(b, a % b);
}
```

`gcd(48, 18)` 的调用链是 `(48,18) → (18,12) → (12,6) → (6,0)`，返回6。这是“把问题转换为更小的同类问题”的典型例子。

### 练习5：判断正误

1. 形参与实参同名，因此是同一个变量。——**错**，普通值参数是独立对象。
2. 函数有返回值，调用者就必须接收。——**错**，可以丢弃。
3. static 局部变量可以在函数外直接用名字访问。——**错**，作用域没有扩大。
4. 普通局部 const 对象一定具有静态存储期。——**错**。
5. extern 声明可以代替程序中真正的变量定义。——**错**。
6. 两个源文件可以各有一个同名 static 函数。——**对**，它们是不同实体。
7. 递归函数只要有 if 就一定终止。——**错**，还要检查参数能否到达终止条件。
8. `max2(max2(a,b),c)` 一定是递归。——**错**，要检查函数体是否直接或间接调用自身。
